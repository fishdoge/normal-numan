# 凡人修仙傳 — 版本 2.3

發布日期:2026-08-24

小變動:修煉欄改用對齊格線排版,取代原本按鈕與代價小字擠成高低不齊柵欄的排法。

## 修煉欄格線化

- 四顆按鈕(打坐修煉/調息/雲遊四海/嘗試突破)因文字長短不一,2.2 版「按鈕正下方接一行小字」的排法在 `flex-wrap` 下擠成寬窄不一、高低參差的柵欄狀,看起來不整齊。
- 改用 `grid grid-cols-2 sm:grid-cols-4`(窄螢幕two欄、寬螢幕四欄)搭配 1px 分隔線(`gap-px` + 背景色技巧),四顆按鈕與各自代價小字上下對齊成一張小表格,寬度一致、邊界分明。
- 面板標題「修煉」移到格線上方獨立一行(原本與按鈕同排,格線化後不再適合擠在同一行);修為/突破成功率總覽移到格線下方獨立一行、靠右對齊。

## 技術細節

- `src/components/Game.tsx`:`CultivationBar` 的按鈕容器改為 grid,每個儲存格 `bg-coal/90 p-3 flex flex-col items-center` 包住按鈕(`w-full`)與代價 `<span>`;父層 `bg-faded/15` 搭配子層背景填滿,製造出格線分隔效果,不需額外畫邊框線條。
