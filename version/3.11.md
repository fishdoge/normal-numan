# 凡人修仙傳 — 版本 3.11

發布日期:2026-09-07

找到「雙方狀態」看起來像沒做的真正原因:狀態列原本只在任一方已經中招時才顯示,剛開戰雙方都還沒有任何狀態效果就整個區塊消失不見。這一版改成戰鬥中恆常顯示。另外把「仙法」分頁拆成「百寶袋」「修練」兩個子頁籤。

## 為什麼要改

玩家反覆回報「Figma 明明畫了怪物狀態/我方狀態,為什麼開發都不做」。實際查證:3.9 版其實已經把這塊做進 `CombatPanel` 了,程式碼也一直在跑(本機 `next dev` 服務即時反映每次修改,不是部署或快取的問題)。真正的原因是顯示條件寫錯——`{(monsterStatusChips.length > 0 || playerStatusChips.length > 0) && (...)}`,只要雙方都還沒有任何狀態效果(剛開戰、還沒中燒傷/中毒/冰封,也還沒放護盾)這個區塊就完全不渲染,連「怪物狀態」「我方狀態」這兩行標籤都看不到。玩家看到的「空白」不是漏做,是條件式判斷把整個功能藏起來了。

## 狀態列改為恆常顯示

拿掉外層的「任一方有狀態才顯示」判斷,只要在戰鬥中,「怪物狀態」「我方狀態」兩行一律顯示,沒有效果的一側顯示「—」,不會再讓人誤以為這塊完全沒做。

## 仙法分頁拆成兩個子頁籤

- **百寶袋**:符寶袋內容調整(選符入袋,基礎卡片/仙法分開列,+/− 張數)。
- **修練**:修習中進度 + 增靈珠強化牌組傷害(原本的仙法升級列表)。

兩者原本疊在同一頁,現在用頁籤切換,對應玩家的說法:「一個是可以選擇符寶的組合,另外是可以選擇強化牌組的傷害」。

## 相容性

純顯示邏輯與 UI 結構調整,沒有新增或修改任何存檔欄位。
