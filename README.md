# 凡人修仙傳 · 文字修仙遊戲

以《凡人修仙傳》為藍本的文字修仙遊戲。Next.js 15 + Tailwind CSS 3 + Zustand,中文傳統風格(暖黑宣紙質感、紙紋噪點、燙金框角、Noto Serif TC 襯線)。

## 啟動

```bash
npm install
npm run dev     # http://localhost:3003
```

存檔自動保存在瀏覽器 localStorage(key: `fanren-save`),重新整理不會丟失。「兵解重修」/「轉世重修」可清檔重來。

## 核心資源

| 資源 | 說明 |
|---|---|
| 靈石 | 交易貨幣。擊殺妖獸掉落、售賣物品(六折)、完成任務獲得;坊市購物、煉器消耗。戰敗遺失一半 |
| 仙靈力 | 施展仙法的能量。打坐、調息、丹藥回復 |
| 修為 | 突破境界的積累。打坐、殺妖、服藥、奇遇獲得 |
| 壽元 | 生命年限。調息一日 -10 載,壽盡則亡 |
| 氣血 | 戰鬥生命值。歸零即戰敗(損失一半靈石) |

## 境界系統(26 階,直通飛昇)

煉氣 → 築基 → 結丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫 → 真仙(飛昇)

- 每個大境界分前期/中期/後期
- 小境界突破成功率 95%;後期衝大境界是大關(築基 85% 遞減至渡劫 30%),失敗損失兩成修為
- 打坐收益為境界百分比制,任何境界約 20 次打坐一小階
- 渡劫成功即白日飛昇,遊戲通關

### 壽元年限(原著設定)

| 境界 | 壽元上限(載) |
|---|---|
| 煉氣期 | 150 |
| 築基期 | 300 |
| 結丹期 | 600 |
| 元嬰期 | 1,200 |
| 化神期 | 2,500 |
| 煉虛期 | 6,000 |
| 合體期 | 15,000 |
| 大乘期 | 40,000 |
| 渡劫期 | 100,000 |
| 真仙 | 無壽 |

- 開局 16 歲。每日最多修煉 3 次,滿了須「調息一日」(壽元 -10 載,氣血仙靈力全滿,重置次數)
- 大境界突破成功:壽元上限躍升,並額外贈壽(新上限 10%)
- 大境界突破失敗:被困於當前壽元上限——剩壽不足兩成時道籍面板轉紅警示
- 壽元耗盡 → 死亡結局(墓誌銘 + 轉世重修)

## 五行相剋

金克木 · 木克土 · 土克水 · 水克火 · 火克金

- 相剋傷害 ×1.5,被剋 ×0.75
- 仙法、法器、妖獸皆有五行屬性,對症下藥事半功倍

## 仙法(17 種)

- 入門五術:青木劍訣、水月箭、金刃術、火彈術、土刺術
- 中階秘笈:青竹蜂雲劍訣、雷遁術、寒冰破、烈火符陣、大衍訣
- 高階神通:金雷竹御雷真訣(築基)、玄天斬靈劍法(結丹)、傲寒六訣/大庚劍陣(元嬰)、元磁神光(化神)、三焰化火(煉虛)、真龍九變(大乘)

秘笈於探索中尋獲、boss 掉落或坊市購買,在儲物袋「參悟」習得,高階需相應境界。

## 煉器(13 配方)

名品:青竹蜂雲劍(金雷竹×3)。
頂階(全為原著法寶):金剛璃甲、大庚劍陣、風雷翅、三焰扇、元磁神山、真龍璽。

## 隨機奇遇(修煉/採集時觸發,獎勵隨境界縮放)

- 小綠瓶(3%,未得時):韓立的掛機外掛。修煉/採集蘊養綠液,滿 3 滴「滴灌藥圃」催熟仙草 + 大量修為,5% 機率結出延壽果
- 頓悟(3%,已得小綠瓶後):修為大增
- 隕落修士遺蛻(3%):拾靈石
- 靈猴贈草(2%):隨機仙草
- 散修順手牽羊(1.5%):損失一成靈石(負面)
- 老道手談(1.5%):道韻加修為
- 救人得大還丹(結丹後 1.5%)
- 上古洞府出世(元嬰後 1.5%):搶得高階秘笈
- 延壽極品(合計 ~1.2%):萬壽丹/延壽果/蟠龍壽桃

## 宗門任務(執事堂,8 件)

獵殺類(清剿鼠患、獵狼護道、誅殺火蟒、斬蛟除害)按接取後擊殺數計;繳納類(採辦藥材、礦石徵集、寒潭取精、雷竹難求)繳材料換賞。獎勵靈石+修為,部分另賜物品(護身符、回元丹、築基丹)。同時僅可領一件,可放棄。

## 修仙榜

與原著人物同榜競逐,名次即時計算(境界優先,同境界比修為):

韓立(渡劫·掌天瓶主)、玄骨老怪(大乘)、銀月(合體)、南宮婉(煉虛)、紫靈仙子(化神)、董萱兒/陳巧倩(元嬰)、墨大夫(結丹)、厲飛雨(築基)、張鐵(煉氣)

超越韓立,便是天下第一。
