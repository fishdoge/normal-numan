# 凡人修仙傳 — 版本 1.24

發布日期:2026-08-24

小變動:主要三欄版面斷點修正、道具說明/裝備屬性/行動按鈕的 UI 整理、九大行動頁籤改自然換行、宗門仙境資料不同步問題修復。本版起版號規則正式生效(見 README「版號規則」),往後只有新系統/新機制才會前進大版號。

## 版面修正

- 主要三欄 grid(`md:grid-cols-[300px_1fr] lg:grid-cols-[300px_1fr_340px]`)的中欄 `1fr` 改為 `minmax(0,1fr)`,並補上 `min-w-0`:未最大化視窗常落在 768~1023px 之間,中欄裡的圖鑑分頁列、大陸遊歷按鈕等內容原本會把 `1fr` 軌道撐開超出可用寬度,擠壓左右欄比例;`minmax(0,1fr)` 讓軌道以實際可用空間為準,不再被內容撐開。

## UI 整理

- **道具說明**:儲物袋/坊市/黑市/交易行列表原本用滑鼠懸停彈出的提示框,在緊湊列表中會蓋住下一列項目,視覺上像「跑出格子」。改回說明文字直接顯示、不截斷,不需懸停即可看到完整內容。
- **裝備屬性**:道籍面板「裝備」欄位(法器/法衣/護身符/符籙/靈寵/命器)新增滑鼠懸停提示,顯示攻/防/速等加成與描述,不需另外查閱。共用邏輯抽出為 `src/i18n/itemText.ts` 的 `itemStatLine()`,與混沌萬靈榜共用同一份文字。
- **精力字樣**:打坐/調息/雲遊四海/煉器煉丹/採集/獵殺等按鈕上原本直接印著「-N 精力」的字樣移除,一律改成滑鼠懸停(`title`)才顯示,精力不足時仍優先顯示警示文字。
- **採集/獵殺精力減半**:`ENERGY_COST.gather` 8→4、`ENERGY_COST.hunt` 10→5。
- **行動頁籤列**:九大頁籤原本窄螢幕下 `overflow-x-auto` 橫向捲動,改回依文字寬度自然換行(`flex-wrap`),寬度足夠時排成兩排;按鈕降低高度、統一補上外框(未選取狀態原本是透明邊框、視覺上等於沒框),文字加上 `whitespace-nowrap` 避免版面較窄時在按鈕內部斷行。

## 宗門仙境資料修復

- `/api/sect` 兩處 `to_jsonb(${變數})` 因缺乏型別上下文,被 Postgres 判定為 `unknown` 型別而丟出 `NeonDbError`(could not determine polymorphic type),導致「進駐仙境」與整份 GET 查詢當場 500——補上 `::int` 轉型。
- `myDwellingSlot` 原本只信任 `saves.dwellingSlot` 快取欄位,若與 `sect_dwelling` 實際佔用紀錄不同步(例如測試資料直接寫入資料庫),會導致已停泊的位置判斷不到「是我」,「離開仙境」按鈕因此消失、且無法正確累算仙境修為。改以 `sect_dwelling.occupant_user_id` 為準,GET 查詢當下偵測到不同步即自動校正回寫 `saves.dwellingSlot`。
- SectPage「離開仙境」按鈕從整份位置列表最上方移入自己停泊的那張卡片內;「升級」按鈕(任何同門皆可出資,與是否停泊無關)獨立成一個附說明文字的區塊,不再緊貼著停泊者資訊,避免看起來像是停泊者專屬操作。
