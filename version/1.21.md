# 凡人修仙傳 — 版本 1.21

發布日期:2026-08-14

延續 1.20 版的中/英語言切換基礎建設,本版將翻譯範圍從「介面框架」大幅擴大到「遊戲內容資料」本體。

## 新增:遊戲內容資料全面翻譯

新增 6 個獨立英文對照表(`src/i18n/itemText.ts`、`monsterText.ts`、`techText.ts`、`sectText.ts`、`realmText.ts`、`worldText.ts`),依原始資料的 `id` 查詢對應英文,中文本身不受影響、仍以 `src/game/data/*.ts` 原始資料為準:

- **物品**:137 種(材料、仙草丹藥、法器護身、符籙、靈寵、命器、秘笈圖譜、奇珍仙物等全分類)的名稱與描述。
- **妖獸**:71 種(含天南至靈界六大區域、北寒/金源仙域、蠻荒異界、地域王、浮屠塔幻象、雲遊超級 BOSS)的名稱與描述。
- **仙法**:36 門(入門五門派法術至真仙/金仙/太乙頂尖仙法)的名稱與描述。
- **門派**:5 大越國門派名稱與描述。
- **境界**:28 個境界名稱(煉氣期前期 → 太乙境)。
- **宗門**:7 級宗門規模名稱、4 個晉升境界門檻標籤、10 件宗門任務名稱與描述。
- **大陸地圖**:8 大區域、23 處秘境的名稱與描述,以及 20 則煉器配方描述。

## 新增翻譯的介面文字

- 戰況欄:「激戰」「⚠ 王者降臨」「⚠ 浮屠塔」標題、「地域王」「幻象」標籤、「法器攻擊」「遁走」按鈕。
- 死亡畫面墓誌銘(境界名稱、年歲、修行年數皆隨語言切換)。
- 拜入門派畫面(CharCreate):門派名稱/描述/入門仙法名稱。

## 涵蓋範圍(顯示層)

以下畫面中凡是引用上述資料的名稱/描述,皆已隨語言切換正確顯示:儲物袋、仙法、煉器、坊市(含黑市)、交易行、妖獸圖鑑、混沌萬靈榜、排行榜與角色詳情卡、宗門頁面(仙境/任務/傷害加成來源/同門名錄/倉庫/宗門列表)、拜入門派畫面。

## 尚未翻譯(下階段工作)

- `engine.ts` 各動作(打坐、調息、雲遊、突破、探索、戰鬥、煉丹、煉器……約 30 種動作)動態產生、寫入見聞錄的敘事文字。這些文字是伺服器端 template literal 直接組字串寫入存檔的 `log`,尚未有語言參數機制,是全站翻譯最後、也是份量最大的一塊,需要先決定架構(伺服器雙語產生 / 前端依結構化資料模板重組)才能著手。
- 修仙入門錄(GuideModal)內文、更新公告(ChangelogModal / `changelog.ts` 逐版條目)。
- 宗門頁面部分靜態說明文字與分頁標籤(宗門仙境/宗門任務/傷害加成來源/同門名錄/宗門倉庫/宗門列表)。

## 技術細節

- 各對照表提供 `xxxDisplayName(obj, lang)` / `xxxDisplayDesc(obj, lang)` 輔助函式:中文語系直接回傳原始欄位,英文語系查表、查無對應時安全回退為原始中文(不會因遺漏條目而顯示空白或報錯)。
- `itemText.ts` 額外處理品質浮動道具(`"id@113"` 格式):先拆出基底 id 查英文名稱,再重新接回原本的 `(+13%)` 百分比後綴。
- `panels.tsx`、`ActionTabs.tsx`、`SectPage.tsx`、`Game.tsx`、`CharCreate.tsx` 皆新增 `const lang = useGame((x) => x.language);` 並將原本直接讀取 `.name`/`.desc` 的位置改為呼叫對應的 `xxxDisplayName`/`xxxDisplayDesc`。
- `dict.ts` 新增 `combatFierce`/`combatLordArrives`/`combatFutu`/`combatIllusionChip`/`combatLordChip`/`btnWeaponAttack`/`btnFlee`/`deathHeadline`/`deathEpitaphTitle`/`deathLine1~3` 等鍵值。
