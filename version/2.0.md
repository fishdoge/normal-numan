# 凡人修仙傳 — 版本 2.0

發布日期:2026-08-24

大變動:新增「乾坤袋」靈石防遺失機制——首個獨立於既有系統之外的全新機制,故大版號自 1.24 前進至 2.0(小版號歸零)。隨附金源仙域/蠻荒異界新素材與三種回復類丹藥。

## 新增:乾坤袋(黑眼貔貅專屬掉落)

- 新道具「乾坤袋」(`qiankun_dai`,special、dropOnly),唯蠻荒異界貔貅領地地域王【黑眼貔貅】掉落(機率 8%)。
- `SaveData` 新增 `pouchStones`,與既有 `stones` 完全分開計算與儲存。
- 新增 `depositPouch`/`withdrawPouch` 兩個動作(需持有乾坤袋方可使用):將靈石存入/取出乾坤袋,儲物袋頁籤新增對應存取 UI(僅持有乾坤袋時顯示),道籍面板靈石欄位下方一併顯示袋中結餘。
- 戰鬥失敗遁走時「遺失一半靈石」的既有邏輯只動用 `s.stones`,存入乾坤袋的靈石因儲存欄位天然隔離,分毫不受影響,不需額外特判。

## 新增:金源仙域 / 蠻荒異界素材與回復丹藥

- 新素材「金源聖蓮」(金源仙域,五重仙關全數怪物與地域王皆有機會掉落,五處仙關採集地點亦可直接採得)、「蠻荒靈髓」(蠻荒異界,四大領地全數怪物、四大地域王與兩處採集地點皆補齊)。
- 兩地原本零星分布的既有材料「金源碎晶」「蠻荒隕骨」順手補齊到所有怪物掉落表,讓兩地整體掉落更豐富,不再只有一兩隻怪物才掉得到。
- 「煉器＆煉丹」新增 3 個真仙以上直接可煉(不需圖譜)的丹藥配方:
  - 金源聖體丹:大量回復氣血(+5,000,000)
  - 混沌真元丹:大量回復法力(+3,000,000)
  - 太乙回氣丹:回復精力(+80),同時消耗兩地新素材,象徵兩域機緣合煉
- `ItemDef` 新增 `energy` 效果欄位(道具/丹藥回復精力點數),`useItem`、CraftTab 效果預覽行、`itemStatLine()`(裝備懸停提示 / 混沌萬靈榜共用)三處皆補上對應處理。

## 技術細節

- `src/lib/db.ts`:無資料表異動,`pouchStones` 與其餘 SaveData 欄位一樣存於 `saves.data` JSONB 內,沿用既有「向後相容欄位回填」慣例(讀取時 `s.pouchStones ?? 0`)。
- `src/game/engine.ts`:`ENERGY_COST`、`applyAction` 均無異動;新增的兩個乾坤袋動作與既有 `sell`/`buy` 同層級,邏輯獨立。
