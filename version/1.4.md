# 凡人修仙傳 — 版本 1.4

發布日期:2026-07-22

導入 Prettier 自動格式化(縮排/排版)。

## 本版變更

### 開發工具:Prettier
- 安裝 prettier 3.9.6 與 eslint-config-prettier(避免 ESLint 與 Prettier 規則打架)。
- 新增設定檔 .prettierrc.json:2 空格縮排、雙引號、結尾分號、trailing comma=all、printWidth=100、LF 換行——沿用專案既有風格。
- 新增 .prettierignore:忽略 .next / node_modules / *.md / package-lock.json。
- 資料表 src/game/data/world.ts、items.ts、missions.ts 一併忽略,刻意維持「一筆一行」的緊湊寫法(否則 world.ts 會由 202 行膨脹成 1000+ 行)。

### package.json 新增指令
- npm run format:自動格式化 src 下所有 ts/tsx/js/jsx/css/json。
- npm run format:check:只檢查不修改(可用於 CI)。

### 首次格式化
- 對 src 下除資料表外的所有原始碼跑過一次 npm run format。
- 純排版調整,無任何邏輯/行為變動;lint、format:check、build 全數通過。

## 使用方式
- 想全專案自動縮排:`npm run format`
- 只想檢查有沒有沒排好的檔案:`npm run format:check`
- 編輯器可安裝 Prettier 外掛並開啟「存檔時格式化」,會自動讀取 .prettierrc.json。
