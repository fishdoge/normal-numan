# LDZ 交易風雲傳，交易員得成神之路

> 從一無所有的韭菜,一路扛過歸零、爆倉、被割,最終登頂封神成為「加密教父」的交易員養成放置遊戲。

由 **LDZ 交易團隊** 出品。前身為「凡人修仙傳」文字修仙遊戲,經四階段換皮改造為加密交易題材,原修仙骨架(五行相剋、境界突破、裝備、探索、排行榜)完整保留,全部文案、數值、UI 改為 web3 / 加密貨幣 + 迷因風格。

**技術**:Next.js 15(App Router)+ TypeScript + Tailwind CSS 3 + Zustand + Neon Postgres。
**風格**:加密交易終端(幣安 / TradingView / CoinMarketCap)—— 暗黑底、漲綠跌紅、等寬數據字、`//` 終端符號、跑馬燈行情條。

---

## 啟動

```bash
npm install
npm run dev     # http://localhost:3003
```

- 帳號系統:註冊 / 登入(`/api/auth/*`),存檔存於 Neon Postgres,`.env` 提供連線字串。
- 伺服器權威:所有遊戲邏輯集中於 `src/game/engine.ts`,唯一入口 `POST /api/action`(反作弊,前端不可改獎勵)。
- 「重開帳戶」清檔重來。

### 開發指令

```bash
npm run lint          # ESLint(extends prettier)
npm run build         # 正式編譯
npm run format        # Prettier 格式化(資料表 world/items/missions 除外,保持一筆一行)
npm run format:check  # 檢查格式
```

> **陷阱**:同一 session 內既 `npm run build` 又跑 dev server,build 會覆蓋 `.next` chunk 導致 dev 500(`Cannot find module './NNN.js'`)。解法:`rm -rf .next` + 重啟 dev,不要在 dev 跑著時 build。

## 境界系統(交易員晉級體系,直通封神)

**韭菜 → 接盤俠 → 合約賭狗 → 鑽石手 → 波段獵人 → 鏈上老狐 → 巨鯨學徒 → 華爾街之狼 → 對沖基金操盤手 → 基金經理人(封神)→ 加密教父**

- 每個大境界分前期 / 中期 / 後期。
- 小境界升等成功率 95%;後期衝大境界是大關(韭菜 85% 遞減至華爾街之狼 30%),失敗損失兩成交易量 + 折損最大資產 15%。
- 進修苦研收益為境界百分比制,任何境界約 20 次進修一小階。
- 交易量考核成功即白日封神,成為「基金經理人」;之後靠「家族資本密令」晉升「加密教父」。
