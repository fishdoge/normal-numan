# 凡人修仙傳 — 版本 5.4

發布日期:2026-11-02

仙界大擴充。資料與數值推算都在 `src/game/data/xianExpansion.ts`,`world.ts`、`items.ts`、`tengfu.ts` 在載入時併入。

## 區域與關卡

| 仙域 | 區域(關卡數) |
|---|---|
| 北寒仙域 | 玄冰原(3)、北寒宮(3)、極北冰海(3) |
| 金源仙域 | 五重仙關(5)、金源礦脈(3) |
| 蠻荒異界 | 四大領地(4)、洪荒古林(3)、王庭外圍(3) |
| 真魔界 | 真魔淵(3)、魔城(3) |
| 灰仙界 | 灰仙死域(3)、冥獄(3) |
| 輪迴界 | 忘川(3)、六道(4) |
| 中土仙域 | 南天門(4)、瑤池(3)、光陰長河(4) |

- 既有秘境歸入各仙域的第一個區域;同一仙域內切換區域不花時間,現在位置仍以仙域為單位。
- 遊歷探索在仙域底下多一排區域頁籤,地圖依關卡順序排列。

## 妖獸數值

不逐隻手調,依所在仙域既有一般妖獸的中位數乘上關卡難度(d = 0 第一關 → 1 最後一關):

- 氣血 = 基準 × (0.6 + 0.9d),攻擊 = 基準 × (0.85 + 0.35d),修為與靈石 = 基準 × (0.7 + 0.6d)。
- 區域菁英:每區最後一關 12% 現身,氣血 ×3.2、攻擊 ×1.8、修為 ×4、靈石 ×3。
- 灰仙界的新妖獸同樣無視五行相剋。
- 每關兩隻新妖獸,再沿用上一關的一隻。

## 採集與裝備

- 每區一種材料、一種仙草(仙草可服用回復氣血),新舊秘境都能採集。
- 每個仙域一套裝備:法器、法衣可用該仙域各區材料煉製(另需五行材料,失敗率依仙界配方),護身符、符籙只能從妖獸(0.8%)與菁英(8%)掉落;菁英也有 4% 掉落法器、法衣。

## 第二批(同版)

### 仙界攻擊力 ×3

- 仙界 7 個仙域所有妖獸(含地域王、菁英、派系巡守、真魔守門古龍、一次性秘境 BOSS)攻擊一律 ×3,數值直接寫回 `world.ts`;新關卡的基準攻擊同步 ×3。
- 浮屠塔的幻象太歲攻擊另依 `tierBaseAtkOf` 計算,不受影響。修仙入門錄「計算公式」頁的階層基準攻擊表也還是 ×3 之前的值。

### 材料、圖譜與掉落

- 每個仙域 3 種新材料 + 1 種仙草,全仙域的秘境都採得到。
- 該仙域所有妖獸(含既有的)追加掉落:一般妖獸每種材料 8%、仙草 6%、每張圖譜 0.4%;地域王與菁英材料 35%、仙草 30%、圖譜 5%。
- 21 張圖譜(每仙域 3 張),研讀後解鎖該仙域的進階法器、法衣、符籙,數值比基本套裝高約兩成。

### 煉丹失敗與命器

- 煉丹失敗率 = min(25%, 2% + 2% × 配方階層);失敗時靈石耗盡、材料損失一半、壽元照耗,同樣累積煉丹心得。
- 裝備中的命器:突破加成同時降低煉器、煉丹(含玄天仙器)的失敗率;消耗型命器煉製時不會耗去。
- 煉器、煉丹本來就每次消耗 10 點精力,失敗也照扣,這點沒變。

## 煉製時間與神器(5.4 版補充)

- 十階器具(`reqStage >= 10` 的裝備、符籙、坐騎配方)需要真實時間煉製(`forgeMinutesOf`,crafting.ts):一般仙域裝備 60/90/120 分鐘、圖譜進階裝備 240/300/360 分鐘,依仙域強弱(北寒/金源 → 蠻荒/真魔/輪迴 → 灰仙/中土)。丹藥與十階以下維持即時完成。
- 開爐即扣靈石、精力、五行材料、主要材料(與太乙精魂);失敗率在開爐時定下(含保底與命器),存在 `SaveData.forge`。爐中一次一件。時間到以 `forgeCollect` 出爐才擲成敗;失敗時所有材料(含太乙精魂)與靈石全數損失,只累積煉器心得。
- 玄天仙器煉化:爐火之資 25 仙元石(`XUANTIAN_STONES`)、失敗率 35%(`XUANTIAN_FAIL`,原 40%)、需煉 6 小時。失敗時所有材料全數損失。
- 神器:玄天仙器煉化與道祖神念符(`DIVINE_RECIPE_IDS`)移到煉器堂最下方的「神器」區,篩選列另有紫色「✦ 神器」按鈕。道祖神念符配方 `taiyiSoul: true`,另需太乙精魂一枚(失敗一併損失);成品在儲物袋紫框紫字並標「神器」。
- 失敗規則統一(5.4 版補充):煉器、煉丹、玄天仙器煉化失敗時,所有材料與靈石全數損失(移除 `failLossOf` 的「主要材料損失一半」);煉器心得保底照舊。
- 道祖神念符另加 5 萬防禦(`defBonus: 50_000`,煉製品質浮動 ±30% 同樣套用)。

- 擊殺紀錄 `SaveData.manhuangLordsSlain`:擊敗天狐/真龍/霸下/黑眼貔貅時記錄,集滿四位時四大領地現出 `xuerou_shengdian`(`Location.unlock: "manhuangLords"`,`locationRevealed` 前後端共用)。舊存檔回推:太乙境視為四王已斬,手上的太乙精魂回推對應的地域王。

## 天地靈氣(5.4 版補充)

- `src/game/data/weather.ts`:全服天氣以 12 小時為一段(台灣時間 00:00 / 12:00),由時段編號雜湊決定,不存檔。雷 8%、煞 7%,其餘五行均分。
- 五行天氣 X:X 屬性傷害 +20%、被 X 所克屬性 −20%,玩家仙法(多屬性符寶取最有利)與妖獸攻擊皆套用。雷/煞天氣:玩家仙法 −30%,雷系仙法(名稱含「雷」)或煞屬性仙法不受影響;妖獸不受雷/煞天氣影響。
- 頁首與戰鬥畫面顯示 `WeatherBadge`。測試以 `setWeatherOverride(null)` 預設關閉天氣(`src/game/__tests__/setup.ts`)。
