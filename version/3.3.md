# 凡人修仙傳 — 版本 3.3

發布日期:2026-09-03

符寶戰鬥系統重構(第二階段):回合結構改寫。延續 3.2 版的法力經濟改版,這一版把「打出一張牌」跟「回合結束」拆開——法力允許就能連續出牌,直到玩家主動按下【施法結束】才輪到怪物出手。三階段規劃(法力經濟 → 回合結構 → 符寶化/百寶袋)的第二步,符寶卡片外觀、百寶袋抽棄牌、各門派專屬起始手牌仍留待下一版。

## 為什麼要改

3.2 版把法力池收斂成小額固定值後,這一版才是符寶戰鬥真正「感覺不一樣」的地方:舊制「一次出牌=一整個回合」下,法力再怎麼便宜,一回合也只能用掉一張牌,法力池的意義有限。這一版拆開兩者,法力池才真正變成「這回合要梭哈幾張牌」的戰術資源。

## 回合結構:出牌與回合結束拆開

- `attack`/`cast`/`useTacticCard`/`rerollHand` 不再各自觸發怪物反擊——只套用效果本身(扣法力/消耗道具/換手牌),回合繼續由玩家掌握。
- 新增顯式的**施法結束**動作(對應介面新按鈕):按下後才觸發原本的回合收尾流程(雙方持續傷害結算 → 怪物出手 → 判定勝負),接著直接進入下一個玩家回合。
- 每個新的玩家回合開始,**法力直接回滿**到當下境界的法力上限(不逐回合遞增,一次回滿)。
- 冰封效果維持原本「整回合直接跳過」的設計:动彈不得時,任何動作都會立即觸發回合收尾(不需要按施法結束),與 3.0/3.1 版行為一致。
- 遁走(成功或失敗)不受這次改動影響:失敗照樣直接觸發回合收尾,因為「試圖遁走」本身就是這回合唯一的行動選擇,不會跟出牌組合。

## 法器攻擊:暫時每回合限一次

法器攻擊目前還沒有像玩家原提案那樣消耗法力(那是下一版符寶化要做的事)。連續出牌回合上線後,如果法器攻擊維持完全免費、不受限制,會被無限連打洗傷害,直接破壞法力池作為戰術資源的意義。這一版先用「每回合限一次」頂住這個缺口,等符寶化把法器攻擊也計入法力消耗後,這個限制會自然移除,改成單純被法力池限制。

## 相容性

- 純行為邏輯調整,`CombatState` 只新增一個可選欄位(`attackUsedThisTurn`),既有存檔/進行中的舊戰鬥不需要遷移,首次呼叫任何戰鬥動作時該欄位會自然補上正確的預設值。
- 手牌邏輯(持有制、打出一張補一張)完全不變,符寶化階段才會換成百寶袋抽棄牌。

## 後續規劃

下一版(暫定 3.4)是符寶化階段:仙法改用符寶卡片呈現、百寶袋抽棄牌、同屬性連攜特性、各門派專屬起始手牌、暈眩狀態新增。詳見 `pvp-territory-design.md` 第九節。

## 技術細節

- `src/game/engine.ts`:
  - `CombatState` 新增 `attackUsedThisTurn?: boolean`。
  - `postPlayerTurn`(回合收尾邏輯本體不變)在存活進入下一回合時新增法力回滿與 `attackUsedThisTurn` 重置。
  - `case "attack"`:新增每回合限一次的檢查與旗標設置;成功出手後不再呼叫 `postPlayerTurn`。
  - `case "cast"`/`case "useTacticCard"`/`case "rerollHand"`:成功結算後不再呼叫 `postPlayerTurn`(冰封分支不變,仍會呼叫)。
  - 新增 `case "endTurn"`:顯式觸發 `postPlayerTurn`。
- `src/components/panels.tsx`:`CombatPanel` 新增【施法結束】按鈕;法器攻擊按鈕在 `attackUsedThisTurn` 為真時停用並改變文字提示。
- `src/i18n/dict.ts`:新增 `btnEndTurn`/`btnWeaponAttackUsed`/`combatTurnNote` 中英對照文字。
