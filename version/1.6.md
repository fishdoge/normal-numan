# 凡人修仙傳 — 版本 1.6

發布日期:2026-08-11

平衡稽核後的大型改版:真實時間壽元、修為/靈石灌水漏洞修正、真仙丹渡劫關卡、命器裝備槽、黑市奇遇。

## 壽元:全伺服器統一時間戳

- 新增「真實時間流逝壽元」:每 1 小時真實時間 = 1 年壽元,透過 `saves.last_life_at` 統一時間戳結算,登入/離線皆計算在內。
- 與原本 `cultivate`(打坐)/`rest`(調息)/`wander`(雲遊)各自的耗壽元機制**並存**,兩者都會扣。
- `/api/action`、`/api/save` 於每次請求時,依「現在時間 − last_life_at」補算應流逝的年數,呼叫新函式 `applyRealTimeAging()`,再把消耗的整數小時寫回時間戳(不足一小時的零頭留到下次一併結算)。
- 若累積的真實時間流逝導致壽元耗盡,一律視為道隕(墓誌銘文案獨立撰寫,與打坐/調息壽元耗盡的死法區分)。
- `/api/save` 回傳欄位 `lifeGained` 語意變更:1.5 版是「離線期間額外贈與的壽元上限」(純加成),1.6 版起是「離線期間流逝掉的壽元年數」(消耗)。前端不再另外彈「增壽」訊息,離線流逝的年數改由伺服器寫入見聞錄(`save.log`)統一顯示。

## 灌水漏洞修正:真仙 / 金仙的 expNeed 佔位值

真仙(feisheng)、金仙(jinxian_realm)的突破所需修為 `expNeed` 是刻意設成打不穿的巨大佔位值(9,999,999,999),原意是「這兩個境界不能靠修為突破,只能靠仙物(金魂丹等)」。但下列兩處公式一直直接把 `expNeed` 當基數做百分比運算,導致這兩個境界的獎勵嚴重失真:

- `maybeEncounter`「拾得遺留靈石」事件:真仙期一次奇遇可洗出約 5000 萬靈石,金仙期約 1.2 億——遠超同期其他管道。
- `maybeEncounter`「頓悟」事件、以及 `cultivate`(打坐)本身的修為公式:真仙期**每次打坐**都會灌出約 5.5 億修為,連續打坐約 18 次即可讓修為超過 9,999,999,999 的突破門檻。

修法:上述四處判斷 `realm.stage >= 10` 時一律改以 `realm.hpMax` 為基準重新換算(在所有境界都是有意義的數值),不再使用 `expNeed`。真仙/金仙期的獎勵因此回到與地圖掉落量級相稱的範圍。

⚠ 這個漏洞原本雖然存在,但**沒有實際危害**——因為真仙境的突破成功率被寫死為 0(`Math.random() < 0` 恆假),修為再高也永遠無法用突破繞過金魂丹系統。這次同時新增「命器」可以加成突破成功率,若不修這個漏洞,灌水的修為 + 命器的成功率加成兩者疊加,就會讓真仙玩家能直接賭機率跳過整套金魂丹/浮屠塔/雲遊尋金源仙域的機制。已在 `breakChanceOf()` 額外加一層保護:境界本身成功率為 0 者(即真仙），命器加成一律失效,雙重保險。

## 靈石經濟調整:填補真仙期資金缺口

- 北寒仙域五隻一般妖獸(`bh_hanjiao`、`bh_binghun`、`bh_hanpeng`、`bh_xuanwu`、`bh_hanlong`)靈石掉落改為 200 萬~700 萬區間(依妖獸強度分級遞增),取代最初的「一律 +1,000,000」臨時做法。
- 新增「靈石橫財」:`winCombat` 擊殺任意妖獸時有 10% 機率靈石雙倍,獨立於原本的靈石區間隨機之外,見聞錄與戰利品彈窗會標註「(靈石橫財,雙倍!)」。
- 全部 7 位地域王(`lord_tiannan`、`lord_jindi`、`lord_luanxinghai`、`lord_dajin`、`lord_lingjie`、`lord_beihan`、`lord_jinyuan`)靈石掉落一律以原始數值 ×15。地域王的靈石收益刻意不跟一般妖獸比高低——這幾位的價值主要在稀有裝備/秘笈掉落,×15 只是把原本偏低的靈石順手拉到合理量級。
- 目的:填補「真仙期唯一穩定收入來源(北寒狩獵)」與「雲遊四海單次 1 億靈石」之間過大的資金缺口,同時讓地域王的擊殺價值不再只靠裝備掉落率獨撐。

## 雲遊四海:太上金仙機率 1% → 3%

- 巧遇太上金仙(金仙境超級大 BOSS)機率由 1% 調升至 3%,後續機率區間(探索秘境、直接得天仙丹、永久屬性提升)等寬位移,彼此相對機率不變。

## 新增:真仙丹 · 渡劫飛昇關卡

- 新道具【真仙丹】,唯靈界地域王「太古龍祖」(lord_lingjie)掉落(機率 15%)。
- 渡劫(dujie)→真仙(feisheng)的突破,除原本的修為門檻外,現在**還需持有至少一枚真仙丹**;無論這次突破成功或失敗,真仙丹都會被消耗。
- 缺件時修煉欄會提示「尚未集得真仙丹,無法渡劫」,不會誤判為單純修為不足。

## 新增:命器裝備槽(天命符 / 地運符)

- 新裝備槽「命器」(`mingqi`),`ItemDef` 新增 `breakBonus` 欄位,效果為突破成功率加成,不分境界皆生效。
- 【天命符】+5% 突破成功率,大晉地域王「噬天鬼帝」(lord_dajin)掉落,機率 5%。
- 【地運符】+3% 突破成功率,亂星海地域王「萬鱗海皇」(lord_luanxinghai)掉落,機率 6%。
- 兩者皆為 `dropOnly`,坊市/煉器無法取得,只能斬殺對應地域王取得。
- 修煉欄「嘗試突破」按鈕、道籍面板旁均即時顯示目前實際突破成功率(境界基礎值 + 命器加成)。

## 新增:黑市奇遇

- 壽元每經過 20~100 年(隨機門檻),有 50% 機率出現一次限時黑市,販售【黑市萬壽丹】(延壽 50 年,遜於一般萬壽丹的 100 年)。
- 出現後若錯過(下一次門檻到達時仍未購買),黑市會自動散去,不會無限累積。
- 定價隨當前境界動態調整(約為當期 expNeed / hpMax 的 8%),真仙/金仙期同樣改用 hpMax 為基準,避免踩到前述灌水漏洞。
- 修煉欄新增黑市面板與購買按鈕(`buyBlackMarket` 行動)。

## 建置穩定性:字型改為自架

- `next/font/google`(`Noto_Serif_TC`、`JetBrains_Mono`)會在**建置當下**連線 Google Fonts 下載字型檔,Vercel 建置機偶發連不上時整個 build 會失敗(`NextFontError: Failed to fetch ... from Google Fonts`),與程式邏輯無關,純粹是建置期間的網路依賴。
- 改用 `@fontsource/noto-serif-tc`、`@fontsource/jetbrains-mono` 自架:字型檔案隨 `npm install` 一併就緒,建置階段不再需要對外連線,徹底解決此間歇性建置失敗。
- `tailwind.config.ts` 的 `fontFamily` 同步簡化,直接引用字型家族名稱(`Noto Serif TC`、`JetBrains Mono`),不再需要 `next/font` 的 CSS 變數轉接(`--font-serif-tc`、`--font-mono` 已移除)。
- 新增依賴(dependencies,非 devDependencies):`@fontsource/noto-serif-tc`、`@fontsource/jetbrains-mono`。另外開發環境新增 `cross-env`(devDependency),修正 `npm run dev`/`build`/`start` 在 Windows PowerShell 下因行內環境變數語法（`NODE_OPTIONS=...`)不相容而直接報錯的問題。

## 戰敗彈窗

- 獵殺妖獸戰敗(氣血歸零)過去只寫進見聞錄,容易被忽略。現在 `monsterTurn` 會回傳戰敗彈窗,`attack`/`cast`/`flee` 三個行動皆會在戰敗當下跳出置中結果彈窗(紅框,呼應突破失敗的樣式),顯示受創傷害、氣血剩餘(僅剩三成)與遺失的靈石。

## 獨立黑市:長生盒

- 新增常駐商品【長生盒】,與「壽元每 20~100 年隨機出現」的黑市不同,長生盒不受時間門檻限制,坊市頁籤內隨時可購買(300,000 靈石)。
- 開啟後隨機獲得一味延壽丹藥:黑市萬壽丹 50%、萬壽丹 30%、延壽果 15%、蟠龍壽桃 5%。

## 金源仙關 · 第五重:新增護法仙使

- 新增兩隻中型怪物【金源仙使 - 歲金】【金源仙使 - 銳金】,實力弱於金源仙帝(氣血 5500 萬/6200 萬,對比仙帝 2.5 億)。
- `jy_guan5` 的 `monsters` 陣列改為這兩隻,原本直接列在陣列裡的 `lord_jinyuan` 移除——地域王一律只透過既有的 2%~3% 地域王遭遇機制觸發,不再與一般巡查重疊(修正後與其餘六個地域王的處理方式一致)。

## 先天造化丹:築基期直升煉虛期

- 金源仙域全部怪物(含新增的兩隻護法仙使)新增機率掉落【先天造化丹】(一般怪 2%、金源仙帝 4%)。
- 唯築基期(stage 2)修士可服用,服下後直接躍升至煉虛期前期,連跨結丹、元嬰、化神三大境界,修為歸零重新累積,並依正常大境界突破邏輯獲得 10% 增壽贈禮。

## 宗門傷害加成 + 宗門頁籤

- 新增宗門集體戰力加成:依同宗門(含自己)在世(未隕落)且已開局的成員境界人數疊加戰鬥傷害倍率——元嬰 +5%、化神 +7%、煉虛 +9%、合體 +11%、大乘 +15%,每位真仙 +40%,每位金仙 +60%,一律以「每人」為單位疊加(例如 3 位元嬰 = +15%)。
- 技術上由 `/api/action` 在 `attack`/`cast` 行動時額外查一次宗門成員境界分佈,算出倍率後透過 `payload.sectDamageMult` 傳入 `engine.ts` 的傷害公式,`engine.ts` 本身仍維持不直接連 DB 的純函式設計。
- 新增「宗門」頁籤:顯示同門名錄(道號、境界、修為、是否已隕落),以及宗門共享靈石庫——任何成員皆可存入/提領,互通有無。
- 新增資料表 `sect_bank`(`sect_id` 主鍵、`stones` 餘額)與 `/api/sect` route(GET 查詢名錄與庫存,POST 存入/提領,皆為原子交易)。
- 道籍面板(StatusPanel)的宗門名稱改為可點擊按鈕,直接切換到「宗門」頁籤;下方新增「宗門加成 戰鬥傷害 ×N.NN」常駐顯示,輪詢 `/api/sect` 依同門境界分佈即時算出。分頁狀態(`activeTab`)從 `ActionTabs` 內部 state 提升到 Zustand store,讓其他面板也能觸發切頁;`SECT_STAGE_BONUS`/`sectDamageMultOfStages` 移入 `engine.ts` 匯出,伺服器實際套用與前端顯示共用同一份公式,避免兩邊各寫一份而兜不起來。
- 「宗門」頁籤內新增小分頁「傷害加成來源」(預設開啟,另一個是原本的「同門名錄」):列出宗門總加成倍率,並逐一境界(元嬰~金仙)列出目前在世人數、每人加成比例、該境界貢獻的小計加成,人數為 0 的境界仍會列出但淡化顯示,方便玩家一眼看出宗門加成怎麼來的、還缺哪個境界的同門。

## 金源仙域採集 + 五組新配方

- 金源仙關第一~五重過去 `materials`/`herbs` 皆為空陣列,「採集靈材」不僅拿不到東西,直接呼叫還會因為在空池中取值而丟例外。這次補上兩種金源仙域專屬材料(金源靈砂、太乙精金),分配進五重仙關的採集池,同時在 `gather` 加了防呆(池為空時回傳溫和提示而非崩潰,惠及其他仍是空池的地點如北寒仙域)。
- 新增 5 組金源仙域圖譜配方(法器 ×2、法衣、護身符、符籙各 1):金源戮神戟、太虛混元甲、金源護道鏡、誅仙滅魂符、造化戮仙劍,皆需真仙境界、圖譜解鎖後方可煉製。
- 5 張對應圖譜分散掉落於太乙金蟒、混天靈猿、八荒火麒麟、金源仙使(歲金/銳金)身上;參悟圖譜時沿用既有的「圖譜參悟」彈窗顯示解鎖的新配方,不需額外程式碼。

## 新增:蠻荒異界(四大領地)

- 新區域「蠻荒異界」(隱藏,`reqStage: 10`),須集滿五色【異星盤】(金/木/水/火/土,各由一隻金源仙域怪物掉落,機率 8%)方能開啟——遊歷探索頁籤新增常駐進度區塊(X/5)與「開啟蠻荒異界之門」按鈕,開啟即消耗五枚異星盤,新動作 `unlockManhuang`。
- 四大領地各有專屬地域王與一般怪物,獵殺時 3%~5% 機率直接遭遇地域王(高於一般地域 2%~3%)——技術上 `Region` 新增 `lordChance` 區間欄位,`Location` 新增 `lordId` 欄位可覆寫區域統一地域王,讓同一區域下的不同秘境擁有各自的地域王。
- 怪物設計:攻擊力不特別高,但氣血極為堅韌(約金源仙域一般怪物平均氣血的 15 倍,規律怪物氣血 6.5~8 億)。
  - 天狐領地 - 赤尾狐妖(火) / 地域王【天狐】(火,氣血 32.5 億)——戰鬥中三成機率直接避過玩家攻擊,無視命中判定。
  - 真龍領地 - 螭龍衛(木) / 地域王【真龍】(木,氣血 36 億)——反擊時兩成機率攻擊力驟增三倍。
  - 霸下領地 - 石靈龜(土) / 地域王【霸下】(土,氣血 320 億)——氣血為領地一般怪物的整整 40 倍,近乎打不穿的活體城牆。
  - 貔貅領地 - 赤目貅仔(金) / 地域王【黑眼貔貅】(金,氣血 35 億)——戰鬥全程封鎖玩家法術,只能以法器攻擊應戰。
- 四大地域王皆有機率掉落增元丹、增靈珠、天仙丹,以及一定機率(8%~10%)掉落金魂丹,提供真仙飛昇後除金源仙域/浮屠塔/雲遊四海外的第四條金仙之路。

- `statsOf()` 新增 `breakBonus` 回傳值;新增匯出函式 `breakChanceOf(s)`(境界基礎突破率 + 命器加成,上限 99%,境界基礎率為 0 時命器加成不生效)。
- `equipToSlot` / `slotVerb` / `useItem` 的裝備分支、`sell` 的卸裝清理、`ActionTabs.tsx` 的 `EQUIPPABLE`/`BAG_SECTIONS`、`panels.tsx` 的裝備欄位對照,皆已補上 `mingqi`。
- 排行榜玩家資訊卡(`/api/ranking?player=`)新增顯示命器欄位。
