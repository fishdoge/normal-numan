# 凡人修仙傳 — 版本 5.0

發布日期:2026-10-22

全站視覺重做:「夜色仙境」——暗色沉浸式仙俠遊戲介面;並合併 magic-ui 分支的 3.19 版內容(通天閣 PvP、煞氣、真魔界、灰仙界、新裝備與符寶)與數值調整。2.20、3.19、4.2 的存檔都可以直接讀取。

合併過程、衝突處理、測試與模擬數據的完整紀錄見 `version/5.0-merge-report.md`。

## 整體感受

- **全幅月夜山水背景**:整個畫面以月夜群山為底,上方疊一層由淺到深的墨藍遮罩,捲動時背景固定不動,像站在山巔看出去。
- **深色玻璃面板**:所有面板改為半透明深色玻璃(背景模糊)、圓角、玉青細框,拿掉角花等裝飾,畫面更乾淨。
- **好讀的文字**:內文改用思源黑體,基礎字級由 14px 提高到 15px,文字改為高對比的冷白;標題維持思源宋體。數字使用等寬數字,不再用英文等寬字型。
- **色彩分工**:玉青 = 可互動與進度(選中的頁籤、主要按鈕、修為條);淡金 = 標題、境界、稀有物;紅色只用於氣血與警示。原本的暖棕色全部改為冷色系。

## 介面

- **HUD 頁首**:固定在畫面頂端,左邊遊戲標題與紀年,中間顯示目前境界與修為進度條,右邊選單;手機版改為上下排列。
- **版面加寬**:主畫面最大寬度由 1152px 放寬到 1600px;1536px 以上螢幕兩側欄加寬到 340 / 400px。
- **頁籤**:行動頁籤改為分段式切換,選中者玉青底;全站其他「選中」狀態(背包分類、地區、登入/註冊等)也統一改為玉青。
- **按鈕**:圓角玻璃按鈕;可以突破時,「嘗試突破」改為玉青實心按鈕(取代原本閃爍的金框)。
- **宗門殿堂入口**:由紫色漸層改為玉青細框。
- **大陸遊歷地圖**:場景插畫不再壓暗模糊,以原色呈現;秘境印記改為深色圓章,選中者玉青,越階者淡金。手機版隱藏地圖底部提示,避免與印記重疊。
- **戰鬥**:整個戰鬥畫面改為深藍夜戰:場景圖原色呈現、玻璃狀態列、圓角手牌、玉青出牌鈕,血條法力條改為圓角漸層。
- **滕符陣、斬妖得寶與突破慶典**:維持 4.2 版的金屬滕符與金光慶典演出。

## 合併 3.19 版(magic-ui 分支)

- **內容**:通天閣即時 PvP(真仙以上)、煞氣系統、真魔界、灰仙界、「煞」屬性、35 件真仙~太乙裝備、27 張符寶、廣寒界與鯤鵬遺骸兩個一次性秘境。
- **數值(沿用 3.19 的削弱)**:仙靈力每點 ×0.2 → ×0.02;宗門加成 元嬰 3%、化神 4%、煉虛 5%、合體 6%、大乘 8%、真仙 12%、金仙 16%、太乙 25%;妖獸攻擊依 3.19 資料下修;大乘、真仙、金仙、太乙的境界基礎攻擊下修。
- **數值(保留 4.0~4.2)**:仙靈力封頂 ×5、宗門總倍率封頂 ×2、符寶連攜封頂 2 張、妖獸氣血 ×2.5 與攻擊 ×1.5 及各地區倍率、修為打折、新手護體。
- **浮屠塔**:每層氣血 ×1.4、攻擊 ×1.2。
- **新區域整合**:真魔界、灰仙界加入大陸遊歷地圖並各有新插畫;廣寒界、鯤鵬遺骸也有專屬場景;新增兩張六品滕符「真魔血符」「灰仙寂滅符」(滕符共 49 種)。
- **修正**:
  - 通天閣 PvP 法力不會回復、對戰打不完(改為每回合法力回滿)。
  - PvP 套用與 PvE 相同的連攜封頂。
  - 一次性秘境 BOSS 的氣血倍率與血條不一致。
  - 隱藏區域(金源、蠻荒、真魔界、灰仙界)改由伺服器檢查解鎖狀態。
- **資料庫**:會新增 `pvp_presence`、`pvp_matches` 兩張資料表(部署後第一個呼叫 `ensureSchema` 的請求——例如登入——會以 `CREATE TABLE IF NOT EXISTS` 自動建立,不會修改既有資料表)。
