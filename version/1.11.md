# 凡人修仙傳 — 版本 1.11

發布日期:2026-08-12

道籍面板佈局調整(宗門名稱移至道號旁、宗門殿堂按鈕移至修為下方)、修復宗門仙境查詢因錯誤的 SQL 型別轉換而失敗的問題。

## 道籍面板佈局調整

- 宗門名稱由原本獨立一行,改為顯示於玩家道號右側。
- 「XX宗門 宗門殿堂」大按鈕由名稱/境界下方,移至氣血/法力/修為三條進度條之後(修為欄下方)、壽元等其餘欄位之前。

## 修復:宗門仙境查詢失敗

- `/api/sect` 的 GET 查詢先前以 `(data->'dwellingSlot')::int` 直接將 JSONB 轉型為整數,PostgreSQL 並不支援此種單箭號(`->`)取值後的整數轉型,導致每次開啟宗門頁面(仙境為預設分頁)查詢自身宗門資料時即拋出 SQL 錯誤,整個宗門頁面無法正常載入。已修正為與其餘查詢一致的 `(data->>'dwellingSlot')::int`(雙箭號,先取文字再轉型)。
- 順帶優化:`ensureDwellingSlots`(確保宗門依等級應開放的仙境位置皆已建立)原本以迴圈逐一 `INSERT` 每個位置(仙宮階最多需 40 次個別往返),改為單一 `generate_series` 查詢一次補齊,降低高階宗門開啟宗門頁面或執行仙境操作時的延遲。

## 技術細節

- `src/app/api/sect/route.ts`:修正 `dwelling_slot` 型別轉換寫法;`ensureDwellingSlots` 改為單一批次 `INSERT ... SELECT generate_series(...) ON CONFLICT DO NOTHING`。
- `src/components/panels.tsx`(`StatusPanel`):宗門名稱移入道號同一行;宗門殿堂按鈕移至氣血/法力/修為區塊之後。
