# 凡人修仙傳 — 版本 1.23

發布日期:2026-08-23

大幅度調整:新增精力系統、恆紀年世界時間、煉器＆煉丹合併、妖獸獵殺榜、黑市天算術;全站統一儲物袋分類/道具提示框/真仙品級標色/玩家道號境界配色;仙法五行新增「無」屬性;電腦/手機版面走查修正。

## 前置作業:合併 payment 分支

本版開發前,先將先前獨立開發的 `payment` 分支(含 Polar 金流基礎設施、i18n 中英雙語框架、儲物袋七分類、手機版戰鬥自動捲動等)fast-forward 合併進 `main`。該分支已包含「向仙班祈禱」付費復活與黑市消耗型命器/玄命果購買的完整實作,本版黑市新商品(倍力丹、天算術)皆沿用其 Polar 串接模式(`src/lib/payments.ts`、`src/game/data/blackMarket.ts`、`/api/blackmarket`、`/api/webhooks/polar`)。

## 新增:精力系統

- `SaveData` 新增 `energy`(當前精力)、`energyPotionStacks`(倍力丹疊加次數,0~5)。
- `energyMaxOf(s)`:精力上限隨大境界緩慢遞增(非氣血/法力那種指數翻倍),煉氣期 100、每個大境界 +15,再乘上 `1 + 0.1 × energyPotionStacks`。
- `applyEnergyRegen(s, points)`:每 5 分鐘真實時間回復 1 點,`saves` 表新增 `last_energy_at` 欄位,`/api/action`、`/api/save` 依與 `last_life_at` 相同的「只推進已兌現整數份、餘數留到下次結算」算法換算回復點數(離線期間亦持續累積)。
- `ENERGY_COST` 常數表:`cultivate` 5、`rest` 5、`wander` 15、`gather` 8、`hunt` 10、`breakthrough` 20、`craft`/`craftXuantian` 10。戰鬥中每回合的攻擊/施法/遁走不額外收費(已含在啟動獵殺的那次消耗裡)。精力不足時,消耗精力的行動一律無法發起、不扣任何資源。
- 黑市新增「倍力丹」(USD 10):服用後立即精力全滿,並使精力上限永久 +10%,帳號最多疊加 5 顆效果。購買端(`/api/blackmarket`)與服用端(`useItem`)皆有疊加上限防呆,避免真的花錢買到用不了的道具。
- UI:道籍面板新增精力條;修煉欄/遊歷探索/煉器頁籤的行動按鈕皆顯示精力消耗與不足提示。

## 新增:恆紀年世界時間

- 新增 `src/game/data/eraTime.ts`:純函式時間,不需輪詢或寫回資料庫。`WORLD_EPOCH` 常數定義「恆紀元年」起點,`currentEraYears()` 依與壽元相同的比例(1 小時真實時間 = 1 年)由牆上時鐘算出目前總年數,`formatEra()`/`eraLabelText()` 換算成「恆紀 X紀 Y年」(每 100 年一紀)。
- `SaveData` 新增 `bornEra`:`newSave()`(含轉世重修/兵解重修)當下記錄的恆紀年,代表「這一世修仙之旅」的起點。
- UI:標題列常駐顯示目前全服恆紀年;道籍面板顯示「此世始於恆紀 X紀 Y年」;拜入門派畫面顯示創建當下的恆紀年。

## 新增:煉器＆煉丹合併

- `Recipe` 新增可選欄位 `lifeCost`(煉丹配方額外消耗壽元載數,煉器類配方不填即可)。`case "craft"` 支援扣壽元,壽元耗盡即道隕(處理方式與打坐/調息一致)。
- 丹藥/仙物類產出**不**套用裝備專屬的「煉器屬性浮動 ±30%」機制(exp/heal/mp 等效果隨機浮動並無意義,只有 atk/def/speed 適用),直接原樣給予。
- 新增 8 種煉丹配方,涵蓋煉氣~大乘全境界,皆用既有材料:黃龍丹、療傷丹、回元丹、築基丹、凝嬰丹、大還丹、九曲靈參丹、破界丹。
- 新增 2 種真仙專屬丹藥「洗髓丹」(修為大補)、「凝仙丹」(仙靈力小補),需圖譜解鎖方可煉製,圖譜由金源仙域怪物(滄瓓金蟒、混天靈猿)掉落。兩者分別完全複用既有的 `exp`/`xianli` 通用效果邏輯,引擎不需額外特判。
- 新增 8 種各區域特產材料(青雲石/血玉/海心珠/魔炎晶/真靈砂/玄冰晶/金源碎晶/蠻荒隕骨):天南、血色禁地、亂星海、大晉、靈界各補一處採集地點與一隻妖獸掉落;北寒仙域、金源仙域、蠻荒異界(原設計為「只能獵殺不能採集」)則只新增妖獸掉落,不更動採集地點設定。
- `CraftTab` 頁籤更名「煉器＆煉丹」,效果預覽行擴充支援 heal/mp/exp/life/lifePct/xianli,並顯示煉丹消耗的壽元。

## 新增:妖獸獵殺榜

- `/api/ranking` 新增 `type=kill` 分支,以 `jsonb_each_text` 展開 `saves.data->'kills'` 物件並加總,取得每位玩家的累計擊殺總數。
- `RankTab` 的 `Board` 型別新增 `"kill"`,四榜主題色統一改用 `BOARD_STYLES` 對照表(取代原本 futu/其他二選一的寫死邏輯),全部使用字面值 class 組合以避免動態組字串被 Tailwind JIT 掃描漏收。
- 獵殺榜下方新增可收合區塊「妖獸掉落一覽」,逐一列出全部妖獸的掉落物品名稱(套用真仙品級/玄天仙器標色),刻意不顯示機率。

## 新增:黑市「天算術」

- `case "wander"` 新增獨立於原有機緣判定之外的 5% 機率,激發一次性的購買機會(`SaveData.oracleOffered`),不影響本次雲遊原有收穫。
- 新增 `rollOracleItem()`:手動配置權重的真仙等級道具池,涵蓋仙靈力丹到玄天仙器,刻意不用價格反推權重(許多真仙級道具 price 慣例為 0,無法反映實際強弱)。
- 新增 `case "dismissOracle"`:不涉金流的婉拒動作。
- 新增 `src/app/api/oracle/route.ts`(POST 建立 Polar 結帳工作階段、GET 供輪詢)與資料表 `oracle_requests`(狀態機同 `item_purchase_requests`);`/api/webhooks/polar` 擴充第三段嘗試,付款成功當下才真正擲骰決定道具。
- 黑市頁籤新增天算術特殊卡片,僅在 `oracleOffered` 為真時顯示,提供付費與婉拒兩個按鈕。

## 全站統一:儲物袋分類 / 道具提示框 / 真仙品級標色 / 玩家道號境界配色

- 抽出共用常數 `src/game/data/itemSections.ts` 的 `ITEM_SECTIONS`(原本只用於儲物袋),坊市商鋪、黑市、交易行掛賣選單、混沌萬靈榜、宗門倉庫全部改用同一份分類。
- 新增 `src/components/Tooltip.tsx`:純 CSS group-hover 提示框,包住道具區塊後滑鼠移上去顯示完整描述,套用於儲物袋、坊市、交易行、混沌萬靈榜。
- `types.ts` 新增 `isXianItem`/`XIAN_ITEM_COLOR`:達真仙(stage 10)以上需求的一般道具全站統一標紫,玄天仙器維持原本的流動漸層特效優先於此。新增 `src/components/ColoredText.tsx` 的 `renderLootLine`,反查敘事文字裡的「【道具名稱】」token 並依此標色,套用於見聞錄與戰利品/突破/獵殺結果彈窗。
- `types.ts` 新增 `nameColorOf(stage)`:化神以下(stage < 5)綠、化神~渡劫(5~9)藍、真仙以上(≥10)維持流動金紫漸層,套用於道籍面板、排行榜、角色詳情卡、宗門同門名錄、對話集發言者(自己仍維持金色識別)。`/api/chat` 的 GET 新增 LEFT JOIN `saves` 撈目前 `realm_idx`,供對話集依「目前」境界即時配色。

## 新增:仙法五行「無」屬性

- `Element` 型別加入「無」,`ELEMENTS` 陣列維持原本 5 行不變(異星盤/蠻荒異界解鎖等邏輯仍以 5 為基準),另增 `ELEMENTS_WITH_NONE` 供仙法分類 UI 使用。
- `COUNTERS` 改為 `Partial<Record<Element, Element>>`:「無」不參與五行相剋。`ELEMENT_COLOR` 與 `i18n/labelText.ts` 的 `ELEMENT_LABEL_EN` 皆補上對應項目。
- 元磁神光、混元一氣仙訣、誅天神雷金仙法、北冥六真天地訣(原「太乙葫蘆天地訣」)重新歸類為「無」屬性——依描述文字逐一檢視後,僅改真正無五行語彙者;大衍訣、北冥玄天訣描述明確對應土/水,維持原屬性不動。

## RWD 修正

- `ActionTabs.tsx` 九大行動頁籤列改為 `overflow-x-auto` + `whitespace-nowrap` 橫向捲動,取代原本窄螢幕會擠成多行的 `flex-wrap`。
- 原本另外調整過 `Game.tsx` 主要三欄 grid 的斷點(把 768~1023px 的兩欄過渡態改成單欄堆疊),但上線後發現這個寬度區間常見於未最大化的桌面視窗,單欄堆疊反而讓版面比例變得不自然、拉長捲動距離,已改回原本 `md:grid-cols-[300px_1fr] lg:grid-cols-[300px_1fr_340px]` 的兩欄→三欄漸進式佈局。
