# LDZ 交易風雲傳，交易員得成神之路

交易員專屬的養成放置遊戲。Next.js 15 + Tailwind CSS 3 + Zustand,交易員終端風(暗黑底、霜綠霓虹 accent、等寬數據字、Noto Serif TC)。由 LDZ 交易團隊出品。

> **改動日誌**:凡人修仙傳 → LDZ 交易風雲傳 換皮改造,分階段記錄於本檔末尾「## 改動日誌」。

## 啟動

```bash
npm install
npm run dev     # http://localhost:3003
```

存檔自動保存在瀏覽器 localStorage(key: `fanren-save`),重新整理不會丟失。「兵解重修」/「轉世重修」可清檔重來。

## 境界系統(26 階,直通飛昇)

韭菜 → 銅牌交易員 → 銀牌交易員 → 金牌交易員 → 白金交易員 → 鑽石交易員 → 大師交易員 → 精英交易員 → 基金經理人 → 家族基金經理人

- 每個大境界分前期/中期/後期
- 小境界突破成功率 95%;後期衝大境界是大關(韭菜 85% 遞減至精英交易員 30%),失敗損失兩成修為
- 打坐收益為境界百分比制,任何境界約 20 次打坐一小階
- 交易量考核成功即白日飛昇,成為 「基金經理人」

### 壽元年限(原著設定)

| 境界 | 資產上限 |
|---|---|
| 韭菜 | 150 |
| 銅牌交易員 | 300 |
| 銀牌交易員 | 600 |
| 金牌交易員 | 1,200 |
| 白金交易員 | 2,500 |
| 鑽石交易員 | 6,000 |
| 大師交易員 | 15,000 |
| 精英交易員 | 40,000 |
| 基金經理人 | 無壽 |

- 開局 16 歲。每日最多修煉 3 次,滿了須「調息一日」(壽元 -10 載,氣血仙靈力全滿,重置次數)
- 大境界突破成功:壽元上限躍升,並額外贈壽(新上限 10%)
- 大境界突破失敗:被困於當前壽元上限——剩壽不足兩成時道籍面板轉紅警示
- 壽元耗盡 → 死亡結局(墓誌銘 + 轉世重修)
