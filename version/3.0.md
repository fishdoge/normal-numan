# 凡人修仙傳 — 版本 3.0

發布日期:2026-08-31

大更新:戰鬥系統全面改版——仙法卡牌化(出招池隨機亮牌)+ 狀態效果(燒傷/中毒/冰封),取代原本「已學仙法全部隨時可用、純比數值」的舊制。此為獨立於既有戰鬥引擎之上的新機制,依專案版號慣例列為大版號更新。

## 為什麼要改

延續 `pvp-territory-design.md` 設計文件的分析:舊制下玩家能做的唯一決定是「這回合按哪個仙法」,但多數玩家同時只學得起 1~2 門主力仙法,實質上等於沒有選擇——五行相剋系統其實一直都在,只是玩家手上沒有籌碼可以博弈。這次改版把「打」這件事本身變得有策略,PvE 與未來的 PvP 共用同一套規則。

## 仙法卡牌化:出招池隨機亮牌

- 每回合系統從你「已學會的仙法」中隨機抽出至多 **3 張**作為本回合可施展的手牌;已學會的仙法數量不超過 3 門時,直接全數亮出、不刻意藏牌——這個機制只在你真的學得夠多、選不完的時候才產生決策感。
- **法器攻擊不受手牌限制**,永遠可用,是不需要手氣也能穩定出手的保底選項。
- 手牌不合意也無法「換牌」——這回合抽到什麼就是什麼,逼你臨場決定要不要用比較弱的招數硬撐,還是先扛一回合換張新手牌。

## 新增狀態效果:燒傷 / 中毒 / 冰封

狀態效果掛在既有的五行系統上,不獨立發明新屬性池,金/土先不掛狀態,留待驗證這三種好不好玩後再考慮擴充:

| 屬性 | 狀態 | 效果 |
| --- | --- | --- |
| 火 | 燒傷 | 每回合造成目標氣血上限 4% 的持續傷害,持續 3 回合 |
| 木 | 中毒 | 每回合造成目標氣血上限 2.5% 的持續傷害,且攻擊輸出打八折,持續 3 回合 |
| 水 | 冰封 | 目標直接跳過整個回合(不出手、不受擊),持續 2 回合 |

- 命中對應屬性的仙法或法器攻擊時,有 **30% 機率**額外附加狀態,玩家與怪物雙方皆適用(怪物的反擊也可能讓你中招)。
- 同名狀態命中不疊加傷害,只刷新剩餘回合數上限,避免無限堆疊爆炸。
- 狀態套用的當回合就會立即結算一次(例如剛點燃就先燒一下),持續傷害本身也足以單獨擊殺目標,不必靠直接攻擊補刀。
- 戰況欄新增狀態圖示(🔥燒傷 / ☠️中毒 / ❄️冰封)與剩餘回合數顯示,怪物與玩家的狀態分開標色。

## 仙法數值校正

順帶檢查了各級仙法的「威力/法力消耗」效率,修正一個明顯不一致之處:「金雷竹御雷真訣」原本威力數字看起來比同級秘笈仙法高出近一倍(4.2 對比 2.1~2.6),但因法力消耗也高出一倍以上(60 對比 22~28),實際每點法力的效率反而是同級最差的——調整為 5.6,使其法力效率與同級仙法一致,不再是個「數字唬人、實際不划算」的陷阱選項。

## 技術細節

- `src/game/engine.ts`:
  - 新增 `StatusEffect` 型別與 `CombatState.hand`/`monsterStatus`/`playerStatus` 欄位。
  - 新增 `rollHand`(出招池隨機抽牌)、`hasStatus`/`applyStatus`/`decrementStatus`/`atkMultFromStatus`/`tickDot`(狀態效果的套用、判定、持續傷害結算)。
  - `monsterTurn` 開頭新增冰封判定(跳過整回合);反擊命中時依怪物屬性機率附加狀態於玩家。
  - 新增共用函式 `handlePlayerDefeat`(玩家戰敗的統一處理,原本寫在 `monsterTurn` 內,因狀態 DOT 也可能致死而抽成獨立函式)。
  - 新增共用函式 `postPlayerTurn`(玩家出手後的回合收尾:怪物 DOT → 判死 → 怪物出手 → 玩家 DOT → 判死 → 重抽手牌),供 `attack`/`cast`/`flee`(遁走失敗)三處共用,確保狀態效果不論本回合做了什麼動作都會如實結算。
  - `cast` 新增手牌成員檢查(不在手牌中的仙法一律拒絕施展)與冰封判定;`attack`/`cast` 命中時依己方武器/仙法屬性機率附加狀態於怪物。
  - 舊存檔向後相容:`combat` 存在但缺少 `hand` 欄位(部署前就已開打的戰鬥)會在下一次行動時自動補齊。
- `src/game/store.ts`:re-export 新增的 `HAND_SIZE` 常數供前端使用。
- `src/components/panels.tsx`:`CombatPanel` 改為只渲染 `combat.hand` 內的仙法按鈕(法器攻擊不受影響);新增雙方狀態效果的圖示列。
- `src/i18n/dict.ts`:新增手牌說明與狀態效果的中英對照文字。
- `src/game/data/techniques.ts`:「金雷竹御雷真訣」威力數值校正(4.2 → 5.6)。
- 已撰寫獨立測試腳本(以 `applyAction` 直接驅動、佇列式 `Math.random` mock 精確控制分支),涵蓋手牌拒絕/手牌上限截斷/燒傷套用與持續傷害/中毒攻擊力打折/冰封連續跳過並自動解除/狀態持續傷害單獨致死/舊存檔向後相容共 7 組情境、20 項斷言,全數通過;`tsc --noEmit`、`next lint` 皆乾淨無誤;並以全新測試帳號透過真實瀏覽器操作驗證手牌限制的介面渲染與端到端戰鬥流程正常運作。
