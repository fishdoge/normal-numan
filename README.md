# 凡人修仙傳 · 文字修仙遊戲

以《凡人修仙傳》為藍本的文字修仙遊戲。Next.js 15 + Tailwind CSS 3 + Zustand,中文傳統風格(暖黑宣紙質感、紙紋噪點、燙金框角、Noto Serif TC 襯線)。

## 啟動

```bash
npm install
npm run dev     # http://localhost:3003
```

存檔為**伺服器權威**:所有操作皆送至 `/api/action`,由伺服器端引擎(`src/game/engine.ts`)運算後寫回 Postgres(Neon)的 `saves` 表,前端(`src/game/store.ts`)只是薄殼,不持有任何遊戲邏輯,可跨裝置繼續進度。需先註冊/登入帳號(`/api/auth/*`)才能開局。「兵解重修」/「轉世重修」可清檔重來。

## 核心資源

| 資源 | 說明 |
|---|---|
| 靈石 | 交易貨幣。擊殺妖獸掉落(10% 機率雙倍,「靈石橫財」)、售賣物品(六折)、完成任務、隨機奇遇獲得;坊市購物、煉器、雲遊四海、聚靈回力消耗。戰敗遺失一半 |
| 法力 | 施展仙法的能量。打坐、調息、丹藥、聚靈回力(耗靈石)回復 |
| 修為 | 突破境界的積累。打坐、殺妖、服藥、奇遇獲得 |
| 壽元 | 生命年限。打坐/調息/雲遊消耗,**且每 1 小時真實時間額外流逝 1 年**(與行動耗壽元並存),壽盡則亡 |
| 氣血 | 戰鬥生命值。歸零即戰敗(損失一半靈石) |

## 境界系統(27 階,飛昇之後還有金仙)

煉氣 → 築基 → 結丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫 → 真仙(飛昇)→ **金仙**

- 前 8 個大境界各分前期/中期/後期(8×3 = 24 階),之後渡劫、真仙、金仙各自單獨一階,共 27 階。
- 小境界突破(前期→中期→後期)成功率 95%;後期衝下一個大境界是大關,成功率隨境界遞減、失敗損失兩成修為與一成半最大壽元:

  | 大關 | 成功率 |
  |---|---|
  | 練氣 → 築基 | 95% |
  | 築基 → 結丹 | 85% |
  | 結丹 → 元嬰 | 75% |
  | 元嬰 → 化神 | 65% |
  | 化神 → 煉虛 | 55% |
  | 煉虛 → 合體 | 50% |
  | 合體 → 大乘 | 45% |
  | 大乘 → 渡劫 | 40% |
  | 渡劫 → 真仙(飛昇) | 30% |

- **渡劫 → 真仙**除修為達標外,還需持有一枚【真仙丹】(唯靈界地域王「太古龍祖」掉落),且無論突破成敗皆會耗盡真仙丹。
- 打坐收益為境界百分比制,任何境界約 18~20 次打坐一小階。
- 修煉欄的「嘗試突破」按鈕會即時顯示目前實際成功率(境界基礎值 + 命器加成,詳見下方)。
- **真仙 → 金仙不能靠修為突破**(所需修為是刻意設定打不穿的巨大數字),必須服用【金魂丹】——來自浮屠塔每 10 層必得、金源仙帝/太上金仙稀有掉落。金仙是目前遊戲的真正頂點。

## 壽元機制

### 打坐/調息/雲遊耗壽元

- 打坐修煉:耗壽元 `5 × 2^(境界-1)` 年,隨大境界翻倍(練氣 5、築基 10、結丹 20、元嬰 40……渡劫 1280、真仙 2560、金仙 5120)。
- 調息(回復氣血):耗壽元為打坐的 2 倍。
- 雲遊四海:固定耗 5000 年壽元 + 100 極品靈石。

### 真實時間壽元(1.6 版新增)

- 全伺服器統一時間戳:**每 1 小時真實時間 = 1 年壽元**,登入操作或單純離線都會計算,與上述行動耗壽元並存(兩者都扣)。
- 由 `/api/action`、`/api/save` 於每次請求時依伺服器時間差自動結算,不需要玩家手動觸發。
- 壽元耗盡(不論來自行動或真實時間流逝)即道隕,進入「轉世重修」流程。

### 壽元上限(依 `realms.ts`)

| 境界 | 壽元上限(載) |
|---|---|
| 煉氣期 | 120 |
| 築基期 | 200 |
| 結丹期 | 400 |
| 元嬰期 | 1,200 |
| 化神期 | 2,000 |
| 煉虛期 | 6,000 |
| 合體期 | 15,000 |
| 大乘期 | 40,000 |
| 渡劫期 | 100,000 |
| 真仙 / 金仙 | 無壽 |

- 開局 16 歲。大境界突破成功:壽元上限躍升至新境界數值,並額外贈壽(新上限 10%)。
- 大境界突破失敗:修為損失 20%,最大壽元折損 15%——剩壽不足兩成上限時道籍面板轉紅警示。

| 萬壽丹 | +100 載 | 奇遇、鬼母掉落 |

## 大陸遊歷(7 區域 20 秘境,照原著路線 + 真仙專屬仙域)

| 區域 | 需求 | 秘境 |
|---|---|---|
| 天南 · 越國 | 煉氣 | 彩霞山、黑風嶺、萬年寒潭、炎火谷、雷鳴竹林 |
| 血色禁地 | 結丹 | 血色河谷、禁獸山古洞 |
| 亂星海 | 元嬰 | 外海群島、星宮遺跡 |
| 大晉皇朝 | 化神 | 魔淵、陰界裂隙(煉虛) |
| 靈界 | 合體 | 天淵城外圍、飛昇台(大乘) |
| 北寒仙域 | 真仙 | 玄冰仙原、北寒仙殿(真仙期主要靈石收入,一般妖獸每次 200~700 萬) |
| 金源仙域(隱藏) | 真仙 | 五重仙關(雲遊探索秘境解鎖,強度為北寒 50 倍) |

每個秘境可「採集靈材」(35% 遇襲)或「獵殺妖獸」,並有機率撿到仙法秘笈。金源仙域第五重仙關為金源仙帝坐鎮,身後即是無盡挑戰的浮屠塔。

### 浮屠塔(金源仙域,真仙專屬)

塔中是一尊「幻象太歲天尊」,每通關一層便更強(氣血 ×1.5、攻擊 ×1.2),無盡挑戰,記錄個人最高通關層數。獎勵:靈石隨層數遞增;每 5 層必得天仙丹、每 10 層必得金魂丹;第 15 層起有機率得《太清道韻九轉》、第 30 層起有機率得《誅天神雷金仙法》。

## 妖獸圖鑑(53 種,含地域王與超級 BOSS)

- 天南(8 種一般 + 3 種常見變體)、血色禁地(6 種)、亂星海(6 種)、大晉(6 種)、靈界(6 種)
- 北寒仙域(真仙專屬,6 種,掉落先天仙器)、金源仙域(隱藏地圖,5 種,強度為北寒 50 倍)
- 地域王(極稀有,獵殺時 2%~3% 遭遇):青元蟒王(天南)、血獄魔君(血色禁地)、萬鱗海皇(亂星海)、噬天鬼帝(大晉)、太古龍祖(靈界)、北寒仙尊(北寒仙域)、金源仙帝(金源仙域)。七位地域王靈石掉落一律為原始數值 ×15,價值仍以稀有裝備/秘笈掉落為主
- 超級 BOSS:幻象太歲天尊(浮屠塔,無盡強化)、太上金仙(雲遊四海 3% 巧遇,掉金魂丹)

## 仙法(21 種)

- 入門五術:青木劍訣、水月箭、金刃術、火彈術、土刺術
- 中階秘笈:青竹蜂雲劍訣、雷遁術、寒冰破、烈火符陣、大衍訣
- 高階神通:金雷竹御雷真訣(築基)、玄天斬靈劍法(結丹)、傲寒六訣/大庚劍陣(元嬰)、元磁神光(化神)、三焰化火(煉虛)、真龍九變(大乘)、北冥玄天訣(真仙,北寒仙尊傳)
- 真仙/金仙頂尖仙法(修煉數十萬載):混元一氣仙訣(真仙,金源仙帝掉落)、太清道韻九轉(真仙,太上金仙/浮屠塔高層)、誅天神雷金仙法(金仙,浮屠塔絕頂)

秘笈於探索中尋獲、boss 掉落或坊市購買,在儲物袋「開始修習」後以打坐推進年月,期滿方成,一次僅能修習一部。法術最高 7 級,以【增靈珠】(地域王掉落)強化,每級威力 +30%。

## 煉器(15 配方)

材料 + 靈石煉製。低階:青索劍、金光巨劍、寒冰錐、火靈旗、厚土盾、烏光甲衣。
名品:青竹蜂雲劍(金雷竹×3)。
頂階(全為原著法寶):金剛璃甲、大庚劍陣、風雷翅、三焰扇、元磁神山、真龍璽。
圖譜解鎖(需妖獸掉落圖譜參悟後方可煉製):玄陰噬魂符(大乘)、太虛混元符(真仙專屬)。

## 裝備(6 槽位)

法器 / 法衣 / 護身符 / 符籙 / 靈寵 / **命器**。坊市、煉器、儲物袋、玩家資訊皆顯示裝備分類。大乘以上裝備坊市不售、一般煉器擋下,只能斬妖奪寶。妖獸掉落「圖譜」,參悟後解鎖藍框配方。靈寵僅探索秘境 5% 得,提供靈石 ×1.2 與攻防加成,等級元嬰→金仙。

**命器**(1.6 版新增):突破成功率加成,不分境界皆生效,唯地域王稀有掉落:
- 天命符(+5%,噬天鬼帝掉落) / 地運符(+3%,萬鱗海皇掉落)

## 隨機奇遇(修煉/採集時觸發,獎勵隨境界縮放)

- 頓悟(3%):修為 +境界所需修為 15%
- 隕落修士遺蛻(2%):拾靈石
- 靈猴贈草(2.5%):隨機仙草
- 散修順手牽羊(1%):損失一成靈石(負面)
- 老道手談(3%):道韻加修為
- 救人得大還丹(結丹後 1.5%)
- 上古洞府出世(元嬰後 1.5%):搶得高階秘笈
- 延壽極品(合計 ~1.2%):萬壽丹/延壽果/蟠龍壽桃

> 1.6 版修正:真仙/金仙的突破所需修為是刻意設定打不穿的巨大佔位數字,原本上述「頓悟」「拾得遺留靈石」與打坐本身的修為公式會誤用這個數字換算,導致真仙期一次奇遇/打坐就能灌出天量靈石與修為。現已改用境界氣血上限(hpMax)為基準重新換算,真仙/金仙期的獎勵回到與地圖掉落量級相稱的範圍。

### 黑市奇遇(1.6 版新增)

壽元每經過 20~100 年(隨機門檻),有 50% 機率出現一次限時黑市,販售【黑市萬壽丹】(延壽 50 年,遜於一般萬壽丹的 100 年)。錯過(下次門檻到達時仍未購買)黑市便自動散去,不會無限累積,修煉欄會顯示黑市面板與購買按鈕。

## 宗門任務(執事堂,8 件)

獵殺類(清剿鼠患、獵狼護道、誅殺火蟒、斬蛟除害)按接取後擊殺數計;繳納類(採辦藥材、礦石徵集、寒潭取精、雷竹難求)繳材料換賞。獎勵靈石+修為,部分另賜物品(護身符、回元丹、築基丹)。同時僅可領一件,可放棄。

## 交易行

全服玩家自由掛賣/購買物品,靈石結算,伺服器端原子交易(下架、搶購、貨款入帳皆為單一交易保證一致)。

## 排行榜(三榜)

- **修仙榜**:境界 → 仙靈力 → 修為綜合排序,與原著人物同榜競逐(韓立、玄骨老怪、銀月、南宮婉、紫靈仙子、董萱兒、陳巧倩、墨大夫、厲飛雨、張鐵等 NPC)。
- **修為榜**:純以修為深淺論高下。
- **浮屠塔榜**:以浮屠塔通關層數論英雄。

三榜皆支援玩家道號搜尋與點擊查看詳細資訊(境界、修為、仙靈力、裝備、浮屠塔層數等公開欄位)。
