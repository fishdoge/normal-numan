# 凡人修仙傳 · 文字修仙遊戲

以《凡人修仙傳》為藍本的文字修仙遊戲。Next.js 15 + Tailwind CSS 3 + Zustand,中文傳統風格(暖黑宣紙質感、紙紋噪點、燙金框角、Noto Serif TC 襯線)。

## 啟動

```bash
npm install
npm run dev     # http://localhost:3003
```

存檔為**伺服器權威**:所有操作皆送至 `/api/action`,由伺服器端引擎(`src/game/engine.ts`)運算後寫回 Postgres(Neon)的 `saves` 表,前端(`src/game/store.ts`)只是薄殼,不持有任何遊戲邏輯,可跨裝置繼續進度。需先註冊/登入帳號(`/api/auth/*`)才能開局。「轉世重修」可清檔重來。

## 境界系統(28 階,飛昇之後還有金仙、太乙境)

煉氣 → 築基 → 結丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫 → 真仙(飛昇)→ 金仙 → **太乙境**

- 前 8 個大境界各分前期/中期/後期(8×3 = 24 階),之後渡劫、真仙、金仙、太乙境各自單獨一階,共 28 階。
- 小境界突破(前期→中期→後期)成功率 95%;後期衝下一個大境界是大關,成功率隨境界遞減、失敗修為直接歸零並折損一成半最大壽元:

  | 大關 | 成功率 |
  |---|---|
  | 練氣 → 築基 | 95% |
  | 築基 → 結丹 | 85% |
  | 結丹 → 元嬰 | 75% |
  | 元嬰 → 化神 | 65% |
  | 化神 → 煉虛 | 55% |
  | 煉虛 → 合體 | 50% |
  | 合體 → 大乘 | 45% |
  | 大乘 → 渡劫 | 40% |
  | 渡劫 → 真仙(飛昇) | 30% |

- **渡劫 → 真仙**除修為達標外,還需持有一枚【真仙丹】(唯靈界地域王「太古龍祖」掉落),且無論突破成敗皆會耗盡真仙丹。
- 打坐收益為境界百分比制,任何境界約 18~20 次打坐一小階。
- 修煉欄的「嘗試突破」按鈕會即時顯示目前實際成功率(境界基礎值 + 命器加成,詳見下方)。
- **真仙 → 金仙不能靠修為突破**(所需修為是刻意設定打不穿的巨大數字),必須服用【金魂丹】——來自浮屠塔每 10 層必得、金源仙帝/太上金仙稀有掉落。
- **金仙 → 太乙境**同樣不能靠修為突破,須浮屠塔登臨第 20 層開啟「太乙殿」,集滿蠻荒異界四大地域王的【太乙精魂】方能突破。太乙境是目前遊戲的真正頂點,且能為所屬宗門帶來 +120% 額外戰鬥傷害。

## 壽元機制

### 打坐/調息/雲遊耗壽元

- 打坐修煉:耗壽元 `5 × 2^(境界-1)` 年,隨大境界翻倍(練氣 5、築基 10、結丹 20、元嬰 40……渡劫 1280、真仙 2560、金仙 5120)。
- 調息(回復氣血):耗壽元為打坐的 2 倍。
- 雲遊四海:固定耗 5000 年壽元 + 100 極品靈石。

### 真實時間壽元(1.6 版新增)

- 全伺服器統一時間戳:**每 1 小時真實時間 = 1 年壽元**,登入操作或單純離線都會計算,與上述行動耗壽元並存(兩者都扣)。
- 由 `/api/action`、`/api/save` 於每次請求時依伺服器時間差自動結算,不需要玩家手動觸發。
- 壽元耗盡(不論來自行動或真實時間流逝)即道隕,可選擇「轉世重修」(清檔重來)或「向仙班祈禱」(付費原地復活,見下方)。

### 向仙班祈禱 · 六道輪迴盤(1.16 版新增,1.17 版改走 Polar 金流,付費復活)

死亡畫面除「轉世重修」外,新增「向仙班祈禱」:支付 15 USD(Polar 金流),由輪迴道祖以【輪迴天生術】原地復活——修為、境界、裝備、庫存等進度**完整保留**,壽元回補至上限八成,不同於轉世重修的全部歸零。**終身僅可使用一次**,用過即永久失效(綁定帳號)。復活的唯一觸發點是伺服器端驗證付款成功的 Polar webhook(`/api/webhooks/polar`,監聽 `order.paid` 事件,官方 SDK 簽章驗證 + 冪等處理),前端無法偽造復活。部署前需至 Polar 後台建立商品並設定 webhook,填入 `POLAR_PRODUCT_ID`/`POLAR_WEBHOOK_SECRET` 環境變數,詳見 `version/1.17.md`。復活成功/失敗皆會跳出置中彈窗告知結果(1.19 版新增,黑市購買結果比照辦理)。

### 黑市(1.19 版新增,USD 計價)

坊市頁籤內「商鋪 / 黑市」切換,黑市不收靈石、只認 Polar 金流。目前販售消耗型命器三款(地命符 $5、天運符 $10、天極符 $20,詳見下方「裝備」章節)與玄命果一款($30,延壽兩萬載)。購買流程與「向仙班祈禱」共用同一套機制:付款成功由伺服器驗證 Polar webhook 後才發放道具,前端無法偽造;`/api/webhooks/polar` 依 checkout id 同時判斷是復活請求還是黑市購買請求,不需額外設定第二個 webhook。

### 宗門仙境(1.9 版新增)

宗門專屬的靜修之地,同門可將角色停泊於此,**每小時真實時間緩慢增長修為**(離線亦持續累積)。位置**數量僅與宗門等級有關**(見上表);各位置本身另有獨立的等級(最高 10 級),須消耗宗門倉庫素材個別升級(任何同門皆可出資,不限本人是否停泊該位),等級越高每小時修為增幅越大(1 級 30 修為/時 → 10 級 22,000 修為/時)。

> 1.10 版新增限制:停泊期間屬閉關潛修,無法再採集靈材、獵殺妖獸、雲遊四海、打坐修煉或調息,須先於宗門頁面離開仙境方可行動。1.13 版再追加:嘗試突破亦不可行,停泊即代表全心閉關。

### 宗門倉庫

同門可將道具存入宗門共享倉庫,任何在冊同門皆可直接提領取用,同時也是宗門晉升與仙境升級所需素材的存放處——素材皆由「採集靈材」「獵殺妖獸」等一般遊歷探索方式取得後存入。

### 浮屠塔(金源仙域,真仙專屬)

塔中是一尊「幻象太歲天尊」,每通關一層便更強(氣血 ×1.5、攻擊 ×1.2),無盡挑戰,記錄個人最高通關層數。獎勵:靈石隨層數遞增;每 5 層必得天仙丹、每 10 層必得金魂丹;第 15 層起有機率得《太清道韻九轉》、第 30 層起有機率得《誅天神雷金仙法》;第 20 層開啟「太乙殿」,集滿蠻荒異界四大地域王的太乙精魂,金仙可於此突破太乙境。

|---|---|---|---|
| 天狐領地 | 赤尾狐妖、白眉狐仙、九尾靈狐 | 天狐 | 三成機率直接避過玩家攻擊 |

四大地域王分別掉落專屬的【太乙精魂】(天狐/真龍/霸下/黑眼貔貅,各 12% 機率),集滿四枚可於浮屠塔第 20 層開啟的太乙殿突破太乙境。全數蠻荒異界怪物皆有機率掉落【玄天殘片】(一般怪 15%、地域王 25%),可與太乙精魂煉成六種隨機的頂級【玄天仙器】之一(屬性浮動 100%~300%,唯太乙境可用)。
