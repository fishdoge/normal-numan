# 凡人修仙傳 · 文字修仙遊戲

以《凡人修仙傳》為藍本的文字修仙遊戲。Next.js 15 + Tailwind CSS 3 + Zustand,中文傳統風格(暖黑宣紙質感、紙紋噪點、燙金框角、Noto Serif TC 襯線)。

## 啟動

```bash
npm install
npm run dev     # http://localhost:3003
```

存檔為**伺服器權威**:所有操作皆送至 `/api/action`,由伺服器端引擎(`src/game/engine.ts`)運算後寫回 Postgres(Neon)的 `saves` 表,前端(`src/game/store.ts`)只是薄殼,不持有任何遊戲邏輯,可跨裝置繼續進度。需先註冊/登入帳號(`/api/auth/*`)才能開局。「兵解重修」/「轉世重修」可清檔重來。

## 境界系統(28 階,飛昇之後還有金仙、太乙境)

煉氣 → 築基 → 結丹 → 元嬰 → 化神 → 煉虛 → 合體 → 大乘 → 渡劫 → 真仙(飛昇)→ 金仙 → **太乙境**

- 前 8 個大境界各分前期/中期/後期(8×3 = 24 階),之後渡劫、真仙、金仙、太乙境各自單獨一階,共 28 階。
- 小境界突破(前期→中期→後期)成功率 95%;後期衝下一個大境界是大關,成功率隨境界遞減、失敗損失兩成修為與一成半最大壽元:

  | 大關 | 成功率 |
  |---|---|
  | 練氣 → 築基 | 95% |
  | 築基 → 結丹 | 85% |
  | 結丹 → 元嬰 | 75% |
  | 元嬰 → 化神 | 65% |
  | 化神 → 煉虛 | 55% |
  | 煉虛 → 合體 | 50% |
  | 合體 → 大乘 | 45% |
  | 大乘 → 渡劫 | 40% |
  | 渡劫 → 真仙(飛昇) | 30% |

- **渡劫 → 真仙**除修為達標外,還需持有一枚【真仙丹】(唯靈界地域王「太古龍祖」掉落),且無論突破成敗皆會耗盡真仙丹。
- 打坐收益為境界百分比制,任何境界約 18~20 次打坐一小階。
- 修煉欄的「嘗試突破」按鈕會即時顯示目前實際成功率(境界基礎值 + 命器加成,詳見下方)。
- **真仙 → 金仙不能靠修為突破**(所需修為是刻意設定打不穿的巨大數字),必須服用【金魂丹】——來自浮屠塔每 10 層必得、金源仙帝/太上金仙稀有掉落。
- **金仙 → 太乙境**同樣不能靠修為突破,須浮屠塔登臨第 20 層開啟「太乙殿」,集滿蠻荒異界四大地域王的【太乙精魂】方能突破。太乙境是目前遊戲的真正頂點,且能為所屬宗門帶來 +120% 額外戰鬥傷害。

## 壽元機制

### 打坐/調息/雲遊耗壽元

- 打坐修煉:耗壽元 `5 × 2^(境界-1)` 年,隨大境界翻倍(練氣 5、築基 10、結丹 20、元嬰 40……渡劫 1280、真仙 2560、金仙 5120)。
- 調息(回復氣血):耗壽元為打坐的 2 倍。
- 雲遊四海:固定耗 5000 年壽元 + 100 極品靈石。

### 真實時間壽元(1.6 版新增)

- 全伺服器統一時間戳:**每 1 小時真實時間 = 1 年壽元**,登入操作或單純離線都會計算,與上述行動耗壽元並存(兩者都扣)。
- 由 `/api/action`、`/api/save` 於每次請求時依伺服器時間差自動結算,不需要玩家手動觸發。
- 壽元耗盡(不論來自行動或真實時間流逝)即道隕,進入「轉世重修」流程。

每個秘境可「採集靈材」(35% 遇襲)或「獵殺妖獸」,並有機率撿到仙法秘笈。金源仙關第五重由金源仙帝坐鎮,兩名護法仙使(金源仙使 - 歲金/銳金)巡弋左右,身後即是無盡挑戰的浮屠塔。金源仙域全數怪物皆有機率掉落【先天造化丹】——築基期修士服下可直升煉虛期,連跨結丹、元嬰、化神三大境界。

### 浮屠塔(金源仙域,真仙專屬)

塔中是一尊「幻象太歲天尊」,每通關一層便更強(氣血 ×1.5、攻擊 ×1.2),無盡挑戰,記錄個人最高通關層數。獎勵:靈石隨層數遞增;每 5 層必得天仙丹、每 10 層必得金魂丹;第 15 層起有機率得《太清道韻九轉》、第 30 層起有機率得《誅天神雷金仙法》;第 20 層開啟「太乙殿」,集滿蠻荒異界四大地域王的太乙精魂,金仙可於此突破太乙境。

### 蠻荒異界(1.6 版新增,真仙專屬)

集滿【異星盤】金木水火土五色(金源仙域怪物稀有掉落,各 8% 機率),於遊歷探索頁籤開啟蠻荒異界之門。四大領地各有一般怪物與專屬地域王(獵殺時 3%~5% 機率直接遭遇,高於一般地域的 2%~3%),怪物攻擊力不特別高,但氣血極為堅韌(一般怪物約金源仙域平均氣血 15 倍,約 6.5~8 億):

| 領地 | 一般怪物 | 地域王 | 專屬異能 |
|---|---|---|---|
| 天狐領地 | 赤尾狐妖、白眉狐仙、九尾靈狐 | 天狐 | 三成機率直接避過玩家攻擊 |
| 真龍領地 | 螭龍衛、蚩龍真靈、龍鱗蜥卒 | 真龍 | 反擊兩成機率攻擊力 ×3 |
| 霸下領地 | 石靈龜、頑石先鋒、厚土玄武 | 霸下 | 氣血為領地怪物的 40 倍(320 億) |
| 貔貅領地 | 赤目貅、聚寶貅獸、銀爪貅衛 | 黑眼貔貅 | 戰鬥全程封鎖玩家法術,僅能以法器應戰 |

四大地域王分別掉落專屬的【太乙精魂】(天狐/真龍/霸下/黑眼貔貅,各 12% 機率),集滿四枚可於浮屠塔第 20 層開啟的太乙殿突破太乙境。全數蠻荒異界怪物皆有機率掉落【玄天殘片】(一般怪 15%、地域王 25%),可與太乙精魂煉成六種隨機的頂級【玄天仙器】之一(屬性浮動 100%~300%,唯太乙境可用)。

- 救人得大還丹(結丹後 1.5%)
- 上古洞府出世(元嬰後 1.5%):搶得高階秘笈
- 延壽極品(合計 ~1.2%):百壽丹/延壽果/蟠龍壽桃

> 1.6 版修正:真仙/金仙的突破所需修為是刻意設定打不穿的巨大佔位數字,原本上述「頓悟」「拾得遺留靈石」與打坐本身的修為公式會誤用這個數字換算,導致真仙期一次奇遇/打坐就能灌出天量靈石與修為。現已改用境界氣血上限(hpMax)為基準重新換算,真仙/金仙期的獎勵回到與地圖掉落量級相稱的範圍。

### 黑市奇遇(1.6 版新增)

壽元每經過 20~100 年(隨機門檻),有 50% 機率出現一次限時黑市,販售【黑市百壽丹】(延壽 50 年,遜於一般百壽丹的 100 年)。錯過(下次門檻到達時仍未購買)黑市便自動散去,不會無限累積,修煉欄會顯示黑市面板與購買按鈕。

### 獨立黑市 · 長生盒(1.6 版新增)

坊市頁籤內另有一個**常駐**的獨立黑市,不受壽元門檻限制,隨時可花 300,000 靈石購買【長生盒】。開啟後隨機獲得一味延壽丹藥(黑市百壽丹 50%、百壽丹 30%、延壽果 15%、蟠龍壽桃 5%)。

### 戰敗提示(1.6 版新增)

獵殺妖獸戰敗(氣血歸零)會跳出置中結果彈窗,顯示受創傷害、氣血剩餘(僅剩三成)與遺失的靈石,不再只靜靜寫進見聞錄。

## 宗門任務(執事堂,8 件)

獵殺類(清剿鼠患、獵狼護道、誅殺火蟒、斬蛟除害)按接取後擊殺數計;繳納類(採辦藥材、礦石徵集、寒潭取精、雷竹難求)繳材料換賞。獎勵靈石+修為,部分另賜物品(護身符、回元丹、築基丹)。同時僅可領一件,可放棄。

## 交易行

全服玩家自由掛賣/購買物品,靈石結算,伺服器端原子交易(下架、搶購、貨款入帳皆為單一交易保證一致)。

## 排行榜(三榜)

- **修仙榜**:境界 → 仙靈力 → 修為綜合排序,與原著人物同榜競逐(韓立、玄骨老怪、銀月、南宮婉、紫靈仙子、董萱兒、陳巧倩、墨大夫、厲飛雨、張鐵等 NPC)。
- **修為榜**:純以修為深淺論高下。
- **浮屠塔榜**:以浮屠塔通關層數論英雄。

三榜皆支援玩家道號搜尋與點擊查看詳細資訊(境界、修為、仙靈力、裝備、浮屠塔層數等公開欄位)。
