# 凡人修仙傳 — 版本 3.1

發布日期:2026-08-31

延續 3.0 版的戰鬥卡牌化方向,針對玩家實測後的回饋(「感覺只是把多數法術拿掉、顯示三種,跟卡牌模式差很多」)做出結構性調整:手牌改為真正的「持有制」、新增可從坊市購入的消耗型戰術卡,並把戰鬥按鈕全面換成卡片外觀。資料庫欄位一律採additive(新增可選欄位)方式擴充,舊存檔與進行中的舊戰鬥不受影響、無需遷移。

## 為什麼要再改一次

3.0 版的手牌機制雖然限制了每回合可施展的仙法數量,但手牌是「每回合整批重抽」——不論玩家做了什麼動作,下一回合都會拿到一組全新的隨機仙法。這在實際體驗上更接近「系統每回合隨機建議三個選項」,而不是玩家熟悉的卡牌遊戲那種「手上握有一組牌,打出一張才少一張」的持有感,也是這次調整要解決的核心落差。

## 手牌改為持有制

- 戰鬥開始時抽一次手牌(規則與 3.0 版相同:至多 `HAND_SIZE`(3)張,已學仙法不超過 3 門時全數亮出)。
- **打出一張仙法後,只有那一張會被換掉**,從「已學會但目前不在手中」的仙法裡隨機補一張;沒打出的牌原封不動留在手中。已學仙法數量太少、無新選項可換時,原張留在手中不變。
- 法器攻擊仍不佔手牌、恆常可用;遁走(不論成功或失敗)、戰術卡皆不影響手牌內容。

## 新增：棄牌重抽

手牌不再每回合自動整批換新之後,「滿手爛牌」就變成玩家需要自行處理的情境,因此新增一個主動選項:

- 花費**法力上限 15%** 的法力,放棄整手仙法、重新抽一手全新的牌。
- 這個動作照樣會結算本回合(怪物依然出手、雙方持續傷害照樣結算),不是免費操作——冰封中無法棄牌重抽。

## 新增：戰術卡

坊市新增一種可購買的消耗型道具分類「戰術卡」,戰鬥中可直接打出(佔用這一回合),提供仙法與法器攻擊之外的第三種決策維度:

| 戰術卡 | 效果 |
| --- | --- |
| 護體法箓 | 立即獲得「氣血上限 20%」的護盾,優先抵擋接下來受到的直接傷害(不擋燒傷/中毒等持續傷害) |
| 洗髓符 | 清除自身當前所有負面狀態效果 |
| 衰運針 | 令敵方陷入新增的「虛弱」狀態 |
| 烈焰印 / 蝕毒針 / 冰封箋 | 分別必定令敵方燒傷 / 中毒 / 冰封,不受一般命中機率限制 |

戰術卡的效果數值(護盾比例、虛弱倍率與持續回合)統一由引擎控制,不隨道具個別調整,避免日後追加卡片時數值失控。

## 新增狀態：虛弱

- 僅由「衰運針」附加,不掛在五行系統上(與燒傷/中毒/冰封的觸發方式不同)。
- 攻擊輸出打七折,持續 2 回合,與中毒的攻擊力懲罰同機制(可疊乘)。

## 戰鬥面板改版

- 法器攻擊、仙法手牌、戰術卡三者統一改為卡片外觀(取代原本一整排看起來都一樣的長條按鈕):卡面左上/右上以圓形徽章標示法力消耗、持有數量或「常駐」標記,卡面下方顯示屬性與威力(仙法)或操作提示(戰術卡)。
- 戰況欄新增護盾圖示(🛡)與虛弱圖示(🔻),與既有的燒傷/中毒/冰封圖示並列顯示。

## 資料庫相容性

本次全部改動皆為**新增欄位**,不改動、不重新命名任何既有欄位:

- `ItemKind` 新增 `"tactic"` 選項;`ItemDef` 新增 `shieldPct?`/`cleanse?`/`enemyWeaken?`/`forceStatus?` 四個可選欄位,既有道具完全不受影響。
- `StatusEffect.kind` 新增 `"weaken"` 選項(既有 `"burn"|"poison"|"freeze"` 不變)。
- `CombatState` 新增 `playerShield?` 可選欄位,預設視為 0,舊存檔/進行中的舊戰鬥無需遷移即可正常運作。
- 手牌邏輯變更(持有制取代整批重抽)完全是行為邏輯調整,未新增或修改任何存檔欄位。
