# 凡人修仙傳 — 版本 1.22

發布日期:2026-08-14

延續 1.21 版的遊戲內容資料翻譯,本版把「介面文字」本身的翻譯覆蓋率補到接近完整——修正玩家回報的「還是很多名詞沒翻譯」問題:上一版只翻了資料(物品/妖獸/仙法名稱),但周圍大量按鈕、頁籤、提示語、錯誤訊息仍是中文,造成中英混雜。這一版把這些缺口逐一補上。

## 新增翻譯範圍

- **遊歷探索**:浮屠塔卡片(標題/說明/按鈕)、地點卡片(境界不足標籤、採集/獵殺按鈕、宗門仙境閉關中提示)。
- **儲物袋**:七個分類頁籤(材料/仙草丹藥/法器法衣護身符符籙/靈寵/命器/秘笈圖譜/奇珍仙物)改用語言無關的識別碼、道具操作按鈕(服用/煉化/裝備/售出/開始修習……)、已裝備/玄天仙器等標籤。
- **仙法**:等級標籤、威力/法力顯示、強化按鈕與提示。
- **煉器**:標頭說明、玄天仙器煉化區塊、圖譜配方標籤、鎖定提示。
- **坊市/黑市**:切換按鈕、購買失敗/成功彈窗文字、突破加成標籤。「美利堅靈石」黑市貨幣名稱英文版譯為 American Spirit Stones。
- **交易行**:掛賣/購買/下架全流程訊息與表單標籤。
- **妖獸圖鑑 / 混沌萬靈榜**:未遭遇提示、屬性標籤、統計數值行、篩選頁籤。
- **排行榜與角色詳情卡**:三榜名稱與說明、裝備槽標籤、境界/門派/修為等欄位標籤。
- **宗門頁面**:六個分頁(宗門仙境/宗門任務/傷害加成來源/同門名錄/宗門倉庫/宗門列表)標籤與內文幾乎全數翻譯,含貢獻靈石、晉升門檻、仙境停泊、執事堂任務、倉庫存提、其餘宗門列表。境界階數標籤(元嬰期~太乙境)新增 `src/i18n/realmText.ts` 的 `stageLabel()` 對照。
- **死亡畫面**:向仙班祈禱付費復活流程(按鈕/彈窗/錯誤訊息)。
- **更新公告框架**:標題、關閉鈕、版本號樣式(條目內容本身仍為中文)。
- **拜入門派畫面**:標語、道號說明、門派卡片加成數值、按鈕。
- **見聞錄/對話集面板**:發送失敗訊息、空狀態提示、輸入框佔位文字。
- **登入畫面**:剩餘兩則錯誤訊息、密碼欄位提示。
- **物品分類 / 裝備槽 / 五行屬性**:新增 `src/i18n/labelText.ts`,提供 `kindLabel()`、`equipSlotLabel()`、`elementLabel()`,取代原本不分語言直接顯示中文字的做法。

## 尚未翻譯(下階段工作)

- `engine.ts` 各動作(打坐、突破、探索、戰鬥……)動態產生、寫入見聞錄的敘事文字——這是全站翻譯最後、也是份量最大的一塊,牽涉伺服器端邏輯改動,需先決定架構(伺服器雙語產生 / 前端依結構化資料重組模板)。
- 修仙入門錄(GuideModal)內文。
- 更新公告(`changelog.ts`)逐版條目本身的文字內容。

## 技術細節

- `src/i18n/dict.ts` 字典鍵值由 1.21 版的 ~250 組擴充至 340 組,涵蓋上述所有新翻譯範圍;每次新增皆同步核對 zh/en 鍵值數量一致,避免遺漏。
- 新增 `src/i18n/labelText.ts`(物品分類/裝備槽/五行屬性英文對照)。
- `src/i18n/realmText.ts` 新增 `STAGE_LABEL_EN`/`stageLabel()`,供只有 stage 數字(無完整 Realm 物件)的宗門加成來源等處查詢境界英文名。
- `BAG_SECTIONS`(儲物袋/混沌萬靈榜共用的分類清單)改用 `DictKey` 作為識別碼而非中文字串本身,篩選狀態不再隨語言切換而失效。
- `src/game/store.ts` 的 `act()` 連線失敗訊息改由 `DICT[get().language]` 直接查詢(store 本身非 React 元件,不能用 `useT()`)。
